# AI Video Prompt OS V5

一套「Prompt DNA 蒸馏 + 可进化知识库 + 生成引擎」的视频提示词系统。

## V5 融合版核心能力

通过五个命令完成视频提示词的全生命周期管理：

| 命令 | 作用 |
|---|---|
| `/蒸馏` | 分析优秀视频 Prompt，提取 6 维 DNA |
| `/学习` | 蒸馏→评分→去重→合并→写回知识库 |
| `/生成` | 检索 DNA→套模板→分阶段产出分镜图+视频 Prompt |
| `/优化` | 局部修正已有 Prompt，不推倒重来 |
| `/同步` | 拉取最新知识库，建立会话索引 |

### V5 融合升级内容

| 模块 | 内容 |
|---|---|
| **P0 基础规范** | 镜头语言速查表（20运镜/7景别/8机位/9光源）+ 多模态引用语法 + 声音内聚化 + 转场显性化 |
| **P1 场景模板** | 12 个高频场景模板（音乐卡点/视频延长/空间漫游/口播/伪纪录片/产品动效/角色动作/情感冲突/风景旅拍/长镜头追踪/战争宏大/产品广告）+ 智能路由 18 项 |
| **P2 质量门控** | 视频提示词 6 条门控（49 检查项）+ 分镜图 5 条门控，输出前强制自检 |
| **分镜图 V5** | 八要素 + 高势能瞬间 + 格间防渗透 + 下游视频映射标签 + 双模式 + 6 风格预设 |
| **中英双文** | 所有提示词强制中英双文输出，先中后英分开不混排，英文过语言一致性门控 |

```
├── knowledge/            # 可进化知识库

│   ├── DNA_schema.json   # DNA 字段规范
│   ├── camera/           # 镜头语言库
│   ├── shot/             # 分镜结构库
│   ├── movement/         # 运镜库
│   ├── transition/       # 转场库
│   ├── action/           # 动作链库
│   ├── lighting/         # 灯光与氛围库
│   ├── audio/            # 声音设计库
│   ├── commercial/       # 商业广告结构库
│   ├── cinema/           # 电影导演手法库
│   └── model_rules/      # 模型专用规则
├── templates/            # 出片模板
│   ├── seedance/
│   ├── tiktok/
│   ├── qianchuan/
│   ├── cinema/

├── learning/             # 学习机制（评分/待审/日志）

├── tests/                # 验收测试用例
└── config/               # 系统配置
```

## 快速开始

1. 复制 `SKILL.md` 到智能体 Instructions
2. 上传 `knowledge/`、`templates/` 作为知识文件
3. 输入 `/蒸馏` 测试部署
4. （可选）连接 GitHub，用 `/同步` 拉取最新知识

## 运行模式

- **本地库模式**：直接读取项目内知识库，无需联网
- **GitHub 增强模式**：`/学习` 自动 commit 到 GitHub，`/同步` 拉取远程最新知识

## 硬性原则

- 产品外观/颜色/logo 以用户图为唯一事实
- 具体工具名不写死，只保留模型分层策略
- 每阶段产物可直接复制使用，不给半成品
- 先验证再放量：先出 2-3 条测方向
