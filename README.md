# AI Video Prompt OS V7 (全域商业版)

一套面向欧美跨境电商（TikTok/FB/亚马逊/独立站）及全域商业交付的工业级视频提示词系统。

**当前版本**：V7.0.0 · 四大商业决策母题 · 创意提案分岔路口 · 见证奇迹微观特写 · 镜头商业标签 · 商品商业物理库

## 核心架构

| 模块 | 作用 |
|---|---|
| **M1-M4 商业决策母题** | M1痛点消解 / M2感官ASMR / M3状态跃迁 / M4空间重构——按品类自动调用对应视听与物理法则 |
| **阶段1三岔路创意提案** | 每单输出2-3个风格迥异方向（高张力冲突/极简感官/生活切片），带AI可行性风控 |
| **6大心理扳机** | 社会越轨冲突/超现实奇观/反向逆反警告/生活灾难翻车/生理性不适/催眠静音流 |
| **The Micro-Proof** | 全片最关键1-2秒不可逆物理特写——见证奇迹瞬间 |
| **镜头商业标签** | HOOK / PAIN / PHYSICS / DEMO / VIBE / TRUST_CTA |
| **商品物理库** | 光学质感+形变力学+触感微距+声学物理，按品类调用 |

## 工作流

```
阶段0 需求对齐与母题判别
  → 阶段1 创意提案分岔路口（2-3方向，等用户选）
    → 阶段2 逐镜头分镜卡片（施工图，等用户确认）
      → 阶段3 最终视频Prompt（中英双文分离，可直接投喂）
```

## 质量门控

- [ ] 前3秒无废话，有明确心理抓手
- [ ] 转场咬合成立（动态遮挡/光影/动势视听桥梁）
- [ ] 物理质感真实（品类专属物理表现，杜绝塑料感）
- [ ] 见证瞬间清晰（Micro-Proof特写）
- [ ] AI无畸变风险（无手部打结/多人混乱同框）
