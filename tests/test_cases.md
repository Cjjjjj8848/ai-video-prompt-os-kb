# 测试用例（tests/test_cases）

> 部署后验收测试：验证五个命令是否正常工作。

## 测试 1：/蒸馏

**输入**：粘贴一个优秀视频 Prompt（可附视频/分镜图）

**验收标准**：输出包含 6 个维度 DNA——镜头、运镜、转场、动作链、时间结构、视觉规则；并最后回复"蒸馏完成。请提供新任务目标，我将生成对应 Prompt。"

## 测试 2：/学习

**输入**：/学习 + 一个优秀 Prompt

**验收标准**：执行评分→去重→合并；输出新增 DNA 编号；learning_log.md 有记录；模式 B 下 GitHub 有 commit。

## 测试 3：/生成

**输入**：/生成 + "我要做一条 15 秒 TikTok 唇膏短视频广告"

**验收标准**：先反问关键细节（产品/人群/风格/素材/模型）；补齐后输出完整分镜提示词（含时间戳/景别/运镜/动作链/台词/音效/@媒体/一致性/模型指令）。

## 测试 4：/优化

**输入**：/优化 + 已有 Prompt + "第 3 镜从 4s 改为 2s，总时长压到 10s"

**验收标准**：只改指定镜头，其余不变，不推倒重来。

## 测试 5：/同步

**输入**：/同步

**验收标准**：输出知识库版本、DNA 条数、各分类库条数统计。
