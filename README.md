## V8.0 新增能力

1. **11模块提示词写作框架**：最终Prompt严格按11模块顺序填写，杜绝想到哪写到哪
2. **人物参考双轨规则**：有参考图锁图不加描述；无参考图写年龄/体型/外貌/皮肤毛孔/皱纹/胡茬/禁磨皮
3. **摄影参数设备选型**：根据剧本选手机/电影机/相机，写焦段+光圈+ISO+白平衡+快门+摄影机高度+人格，不局限DNA
4. **物理因果锁定铁律**：任何形变/开合/弯折动作写全4要素，禁止无接触自形变
5. **负面约束分类写**：按人物/产品/肢体/运镜/色彩/光影/焦点/声音/物理因果分类，不混在一起
6. **人物表演细节**：有人物正脸时写眨眼频率/动作错时（眼先动→头后转→肩膀最后）
7. **色彩逻辑两档**：影棚极简版 / 户外完整版，根据场景自动选
