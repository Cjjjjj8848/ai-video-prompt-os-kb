# Seedance 场景模板库（templates/seedance/scene_templates）

> 12 个高频场景模板，全部遵循 P0 内聚化格式（声音内嵌到分镜+转场显性化）+ 画质一致性三段式。生成时选取对应模板，替换占位符即可。

---

## 模板 1：音乐卡点视频

**适用**：照片卡点、产品展示卡点、转场特效卡点、快节奏短视频

```
【风格】卡点剪辑风格 + {色调} + {情绪}，{时长}秒，{画幅}

【时间轴】
0-X秒：[{景别}] [{运镜}]，[{机位}]，{画面1}，{主体动作}，{光影}
  └─ 转场：{硬切/缩放转场/闪白}（与重拍对齐）
  └─ 声音：[@音频1 第X拍] {动作音} + {对白（可选）}
X-Y秒：[{景别}] [{运镜}]，[{机位}]，{画面2}，{主体动作}，{光影}
  └─ 转场：{转场方式}（与重拍对齐）
  └─ 声音：[@音频1 第Y拍] {动作音}
（按音乐重拍逐镜切换，每镜对应一个节拍）

【BGM总述】@音频1 作为配乐，画面切换与音乐重拍严格同步，{BPM}
【参考】@图片1-N 照片素材（按顺序卡点），@音频1 背景音乐
【画质要求】{分辨率}，{光影}，{景深}，{质感}，{运动模糊}
【一致性锁定】{主体一致性描述}
【禁忌】无字幕水印UI乱码，无{场景特定禁忌}
```

**关键规则**：
- 图片顺序明确：`@图片1 → @图片2 → @图片3`
- 每镜时长 = 60/BPM 秒（一个节拍），或 2 倍/4 倍节拍
- 转场必须与重拍对齐，禁止提前或滞后
- 快节奏卡点每镜 ≤1 秒，慢节奏卡点每镜 2-4 秒

## 模板 2：视频延长/续拍

**适用**：基于已有视频延长时长、续写剧情、补充镜头

```
【风格】延续@视频1的{风格}，{新增时长}秒（生成长度选择新增部分时长），{画幅}

【时间轴】
0-X秒：[{景别}] [{运镜}]，[{机位}]，{新增内容1}，与前视频最后一帧无缝衔接
  └─ 转场：无缝衔接（延续前视频运镜方向和速度）
  └─ 声音：[0.0-Xs] {延续前视频的环境音} + {新动作音}
X-Y秒：[{景别}] [{运镜}]，[{机位}]，{新增内容2}
  └─ 转场：{转场方式}
  └─ 声音：[X-Ys] {动作音} + {情绪音} + {对白}

【要求】保持@视频1的角色一致性、色调一致、动作连贯流畅，与前视频无缝衔接
【BGM总述】延续@视频1配乐风格，{BPM}
【参考】@视频1 原视频（必须提供）
【画质要求】与@视频1保持一致：{分辨率}，{光影}，{景深}，{质感}
【一致性锁定】严格还原@视频1中的角色/产品外观，跨镜保持一致
【禁忌】无字幕水印UI乱码，无角色变形/穿模，无与原视频风格冲突的元素
```

**关键规则**：
- 生成长度必须选择"新增部分"时长，不是总时长
- 第一镜必须与原视频最后一帧的运镜方向、速度、光线衔接
- 明确说明"延续前视频的风格和主体"
- 角色/产品外观必须与原视频一致

## 模板 3：空间漫游/参观视频

**适用**：家装参观、店铺探店、空间展示、样板间漫游、建筑可视化

```
【风格】沉浸式参观体验 + {风格关键词}，{时长}秒，{画幅}

【时间轴】
0-X秒：[{景别}] [{运镜：推进/跟随}]，[{机位：人眼高度}]，{空间1名称}，模拟真实参观行走路线，{空间细节}，{光影}
  └─ 转场：{硬切/匹配剪辑（门框/墙角遮挡过渡）}
  └─ 声音：[0-Xs] 环境音（{空间环境声}）+ 脚步声 + {旁白/口播}
X-Y秒：[{景别}] [{运镜}]，[{机位}]，{空间2名称}，{空间细节}，{光影}
  └─ 转场：{转场方式}
  └─ 声音：[X-Ys] 环境音 + {动作音} + {旁白}
（按空间顺序逐镜推进：入口→空间1→空间2→...→出口/全景）

【BGM总述】{氛围配乐风格}，环境音突出，BGM音量低于环境音
【参考】@图片1 平面图，@图片2 分镜图/设计稿（可选），@视频1 参考运镜（可选）
【画质要求】{分辨率}，{自然光线变化}，{景深}，{材质质感（木纹/石材/布料）}，{运动模糊}
【一致性锁定】空间布局严格按@图片1平面图，材质/颜色/灯光跨镜一致
【禁忌】无字幕水印UI乱码，无空间变形/比例失调，无不符合空间关系的物体
```

**关键规则**：
- 必须提供平面图（@图片1），空间关系要与平面图对应
- 运镜模拟真人行走：人眼高度（1.5-1.7m）、自然推进、可切镜头
- 注意自然光线变化（不同空间窗户位置不同）
- 材质质感必须具体（木纹/石材/金属/布料）

## 模板 4：口播视频

**适用**：知识口播、带货口播、播客视频、人物访谈、教程讲解

```
【风格】{专业播客/自然对话/激情带货}风格，{时长}秒，{画幅}

【时间轴】
0-X秒：[{景别：中近景}] [{运镜：固定/微推}]，[{机位：平视}]，@图片1人物在{环境}中面对镜头说话，{表情/手势}，{光影}
  └─ 转场：{硬切/跳剪（口播常用）}
  └─ 声音：@音频1 作为口播内容（完整使用），[0-Xs] {环境音}
X-Y秒：[{景别}] [{运镜}]，[{机位}]，{B-roll画面/产品展示/文字卡片}，{光影}
  └─ 转场：{硬切/匹配剪辑}
  └─ 声音：@音频1 继续（口播不中断），[X-Ys] {动作音}

【功能】自动生成对口型说话画面，支持情感调整（{激动/平静/悲伤/严肃}），适当加字幕
【要求】保持@图片1人物和@音频1声音跨镜头一致性，口型与音频同步
【BGM总述】{轻量BGM风格}，音量低于人声，不抢口播
【参考】@图片1 人物形象照（必须），@音频1 语音内容（必须）
【画质要求】{分辨率}，{人像布光（蝴蝶光/伦勃朗光）}，{浅景深背景虚化}，{质感}
【一致性锁定】严格还原@图片1人物五官/发型/服装，@音频1声音特征保持一致
【禁忌】无字幕水印UI乱码，无人物五官变形/口型不同步，无背景突兀变化
```

**关键规则**：
- 人物形象图（@图片1）+ 语音音频（@音频1）必须同时提供
- 口播音频完整使用，不中断
- 可插入 B-roll（产品/场景/文字卡片），但口播音频继续
- 明确情感表现要求（激动/平静/悲伤等）
- ⚠️ 暂不支持写实真人脸部素材，建议用风格化形象

## 模板 5：伪纪录片/Vlog 风格

**适用**：日常 Vlog、探店记录、第一人称体验、伪纪录片、悬疑喜剧短片

```
【风格】伪纪录片（Vlog Style）+ 超写实主义 + 固定机位实拍感 + 自然光 + {悬疑/喜剧/治愈}色彩，{时长}秒，{画幅}

【主角】{主角设定：性别/年龄/职业/外形}

【时间轴】
0-X秒（日常铺垫）：[{景别}] [{运镜：手持微晃/固定}]，[{机位：主观/平视}]，场景：{场景描述}，动作：{日常动作}，关键细节：{正常状态描述}，{自然光}
  └─ 转场：{硬切/跳剪（Vlog常用）}
  └─ 声音：[0-Xs] 日常环境音 + {主角自语/对白}
X-Y秒（异常出现）：[{景别}] [{运镜}]，[{机位}]，动作：{动作转变}，高能时刻（核心爆点）：{异常现象描述}，{异常行为细节}，导演备注：{特殊效果要求}，{光影变化}
  └─ 转场：{硬切/闪白（异常出现瞬间）}
  └─ 声音：[X-Ys] 突变音效（异常出现时）+ {环境音突变} + {主角反应对白}
Y-15秒（结尾反转）：[{景别}] [{运镜}]，[{机位}]，动作：{主角反应}，结果：{最终状态}，画面在{结尾画面}中定格（喜剧/悬疑效果）
  └─ 转场：{硬切/渐隐}
  └─ 声音：[Y-15s] {反应音效} + {结尾音乐} + {收尾对白}

【BGM总述】日常环境音为主，异常出现时加入突变音效，结尾{欢快/悬疑}收束
【参考】@图片1 主角形象，@图片2 场景参考（可选）
【画质要求】{分辨率}，自然光（窗边/室内顶光），手持微晃纪实感，{浅/中景深}，胶片颗粒感，{运动模糊}
【一致性锁定】严格还原@图片1主角外形/服装，场景布局跨镜一致，日常段与异常段光线对比明显
【禁忌】无字幕水印UI乱码，无主角变形/穿模，无过于精致的广告感（保持纪实粗糙感）
```

**关键规则**：
- 三段式结构：日常铺垫（0-6s）→ 异常出现（6-11s）→ 结尾反转（11-15s）
- 手持微晃+自然光+胶片颗粒 = 伪纪录片质感
- 异常出现瞬间必须有突变音效+光影变化
- 结尾画面定格制造喜剧/悬疑效果
- 禁止过于精致的广告感，保持纪实粗糙感

- UI 元素必须与参考图一致（位置/颜色/字体）
- 动效音效与 BGM 卡点同步

## 通用规则（所有模板必须遵守）

1. **P0 内聚化格式**：声音内嵌到分镜下方（`└─ 声音：`），转场显性化（`└─ 转场：`）
2. **画质一致性三段式**：【画质要求】+【一致性锁定】+【禁忌】必须完整
3. **多模态引用规范**：@图片/@视频/@音频 必须标注用途，编号全程固定
4. **镜头语言查表**：运镜/景别/机位/光影从 `camera_language_cheatsheet.md` 选取标准写法
5. **产品/人物一致性**：每次出镜重复外观锁定描述，禁止 AI 改动设计
6. **商业合规**：知名角色用 Figure 1/2 替代，真实品牌名用通用名替代，禁止血腥暴力过度描写
7. **🔴 P2 质量门控**：输出前必须逐条过 6 条门控（详见 `knowledge/model_rules/quality_gate_checklist.md`），全部通过才能交付，交付时附门控自检表
8. **🔴 中英双文强制输出**：视频提示词必须输出中英双文版，先中文后英文，分开输出不混排，每版独立完整块方便复制；英文版正文无中文字符残留，过语言一致性门控
