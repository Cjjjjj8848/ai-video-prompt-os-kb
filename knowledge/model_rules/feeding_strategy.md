# 参考图喂图策略（LibTV 全能参考模式）

## 核心原则

不逐镜头给首帧图。给参考素材包，让 libTV 看图+读剧本自由分配。

## 三类喂图

### 1. 人物四视图（每个有近景的人一张）

每张拼格：左脸特写 + 全身正/侧/背 + 固定服装。
- 有台词或近景的人物 → 必给
- 龙套背景人群 → 不给
- 单主角项目 → 1张即可
- 群像项目（如圣诞投影灯5人）→ 每人一张

### 2. 场景效果图（2-4张）

告诉 libTV"成品光影效果长这样"：
- 关键场景的最终效果参考
- 超现实场景必给（容易跑偏）
- 常见场景（会议室/咖啡馆）可不给，靠文字

### 3. 氛围静物图（1-2张）

锁定质感调性：
- 告诉 libTV"要手机实拍感，不要电影大片感"
- 暖调/冷调/手持/稳定器——靠这张图定调

## 口红项目参考喂法

| 类型 | 喂什么 |
|---|---|
| 人物 | 1张主角定妆照（或四视图拼格） |
| 产品 | 每款色号一张产品特写 |
| 场景 | 关键超现实场景2-4张（可后期MJ补） |
| 氛围 | 0-1张（锁定调性） |

## libTV 图片规格

- 格式：jpeg/png/webp/bmp/tiff/gif
- 尺寸：300-6000px（宽高）
- 比例：0.4-2.5（宽÷高）
- 大小：≤30MB
