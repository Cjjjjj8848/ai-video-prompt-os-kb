# 画质与一致性锁定规范（model_rules）

> ⚠️ **强制规范**：所有生成的视频提示词必须包含本规范的核心段落。缺少画质要求、人物一致性锁定或禁忌清单的提示词视为不合格。

## 1. 提示词必须包含的三个锁定段落

每条视频提示词（无论长短）必须在开头或结尾包含以下三个段落：

### 段落 A：画质与风格锁定

```
【画质要求】{分辨率}，{光影方案}，{景深}，{质感风格}，{细节描述}，{运动模糊参数}
```

**必填要素**：
- 分辨率（如 8K / 4K）
- 光影方案（主光源方向 + 软硬 + 阴影）
- 景深（极浅/浅/中，背景处理方式）
- 质感风格（胶片/数码/写实/卡通）
- 细节描述（灰阶/空气感/微尘/材质纹理）
- 运动模糊参数（快门速度或自然运动模糊）

### 段落 B：人物/参考图一致性锁定

```
【一致性锁定】严格还原参考图{五官结构/服装造型/产品外观}，不做{磨皮/美颜/改设计}，保持{真实肤质/颜色/logo/材质}
```

**必填要素**：
- 锁定对象（人物五官/服装/产品外观/颜色/logo）
- 禁止项（不磨皮/不美颜/不改设计/不变色）
- 保持项（真实肤质/原始颜色/材质纹理）

### 段落 C：禁忌清单

```
【禁忌】无{字幕/水印/UI/数字乱码/后期添加元素}，无{畸形/穿模/过度油光/多余肢体}
```

**必填要素**：
- 画面元素禁忌（无字幕/水印/UI/乱码）
- 人物/物体禁忌（无畸形/穿模/多余肢体/过度油光）
- 根据产品补充特定禁忌（如食品类无变质、化妆品类无过敏反应等）

## 2. 标准模板（直接复制使用）

### 完整版（推荐用于所有提示词）

```
【画质要求】8K分辨率，电影级柔和光影，主光源来自{方向}均匀铺陈，无生硬阴影；极浅景深将背景吞噬为散落光斑的深邃虚空，焦点咬住主体细节；模拟自然光胶片质感与细腻灰阶过渡，通透空气感中可见微尘在光线中缓慢浮动，保持1/50s–1/100s自然物理运动模糊。
【一致性锁定】严格还原参考图{五官结构/产品外观/服装造型}，不做磨皮美颜修饰，保持真实肤质/原始颜色/logo/材质纹理，每次出镜角度一致。
【禁忌】整个画面无任何后期添加的字幕、水印或UI，无数字乱码；无畸形手指、多余肢体、穿模、过度油光、画面抖动。
```

### 简版（用于短提示词或快速迭代）

```
【画质】8K，电影级柔和光影，极浅景深，胶片质感，1/50s自然运动模糊。
【一致性】严格还原参考图，不磨皮不改设计，保持真实质感。
【禁忌】无字幕水印UI乱码，无畸形穿模多余肢体。
```

## 3. 各场景适配指南

### 人物出镜视频

```
【画质要求】8K，电影级柔和光影，主光源前方偏上偏左，极浅景深背景虚化，自然光胶片质感，真实肤质毛孔可见，1/50s–1/100s自然运动模糊。
【一致性锁定】严格还原参考图五官结构、真实肤质毛孔与服装造型，不做磨皮与美颜修饰，脸型/肤色/发型跨镜一致。
【禁忌】无字幕水印UI，无数字乱码，无畸形五官/多余肢体/过度磨皮/塑料感皮肤。
```

### 产品展示视频

```
【画质要求】8K，产品摄影级布光，主光源{方向}+辅光{方向}，高光不过曝，极浅景深突出产品，商业摄影质感，材质纹理清晰（金属反光/磨砂颗粒/液体通透），自然运动模糊。
【一致性锁定】严格还原参考图产品外观：颜色{色值}、logo位置、材质{磨砂/亮面/金属}、形状细节，不改变设计，每次出镜角度/光线一致。
【禁忌】无字幕水印UI，无数字乱码，无产品变形/颜色偏移/logo模糊/材质失真。
```

### 多人物/多产品视频

```
【一致性锁定】所有参考图人物/产品严格还原，人物A{描述}、人物B{描述}、产品A{描述}跨镜一致；人物之间肤色/光影统一，产品之间比例关系正确。
```

## 4. 常见错误与修正

| 错误写法 | 问题 | 修正写法 |
|---|---|---|
| "高质量画面" | 太模糊，无具体参数 | "8K分辨率，电影级柔和光影，极浅景深，胶片质感" |
| "人物好看" | 主观描述，无锁定 | "严格还原参考图五官结构，不做磨皮美颜，保持真实肤质" |
| "不要有不好的东西" | 禁忌不明确 | "无字幕水印UI乱码，无畸形手指多余肢体穿模" |
| 只在开头写画质 | 结尾无呼应，模型可能遗忘 | 开头和结尾各写一次画质要求，首尾锁定 |
| 人物参考图只写一次 | 跨镜可能漂移 | 每次人物出镜都标注 @媒体编号 + 一致性描述 |

---

## 5. 与 @媒体引用的配合

- 有人物/产品参考图时，**必须**在【一致性锁定】段落中明确"严格还原 @媒体{编号} 的{五官/外观/服装}"
- 多角度产品参考图，每个角度引用时都要重复一致性锁定
- 无参考图时，【一致性锁定】改为"保持{描述的外观}跨镜一致"

## 6. 检查清单（生成提示词后自检）

- [ ] 有【画质要求】段落，包含分辨率/光影/景深/质感/运动模糊
- [ ] 有【一致性锁定】段落，明确锁定对象+禁止项+保持项
- [ ] 有【禁忌】段落，列出画面元素禁忌+人物/物体禁忌
- [ ] 有人物/产品参考图时，一致性锁定中提到了 @媒体编号
- [ ] 画质要求在开头和结尾各出现一次（首尾呼应）
- [ ] 禁忌清单针对当前产品/场景做了定制补充
