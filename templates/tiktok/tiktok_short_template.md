# TikTok 短视频模板（templates/tiktok）

> TikTok / Instagram Reels / YouTube Shorts 短视频结构模板。

## 结构（15s 默认，可按需改 10s/30s）

```
0-3s    钩子（反转/反常识/错误警告/痛点）
3-7s    痛点/错误引导放大
7-10s   产品亮相 + 首波演示
10-13s  卖点演示/效果变化（动作链完整）
13-15s  利益点 + 合规 CTA
```

## 平台要点

- 画幅 9:16 竖屏
- 前 3 秒必须有钩子，否则划走
- 字幕大字+高对比，无声音也能看
- 口播用目标市场语言
- 参考热门 BGM/音效，但产品音效（ASMR）优先
- 合规：禁 cure/best/#1 等绝对化用语

## 批量变体

- 同风格重构 N 条：换开头/换钩子/换场景
- 跨角度扩展：换需求/换镜头表达/换合规引导
- 先出 2-3 条测方向，数据可行再放量
