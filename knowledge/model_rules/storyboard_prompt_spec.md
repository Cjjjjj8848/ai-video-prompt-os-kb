# 分镜图提示词升级规范（model_rules / storyboard_prompt_spec）

> V5 融合版：九宫格分镜图提示词从基础六要素升级为八要素+全局硬锁定+格间防渗透+下游映射标签+5条专用门控。适用于 NanoBanana / Gemini 生成分镜图。

---

## 1. 双模式区分

| 模式 | 用途 | 九宫格内容 | 下游映射 |
|---|---|---|---|
| **多机位底图模式** | 同一主体多角度，供选首帧 | 9格 = 同一主体9个不同机位/角度 | 选1格作视频首帧，其余备用 |
| **分镜故事板模式** | 按剧本推进，每格对应一个分镜 | 9格 = 9个分镜的画面瞬间（或N个分镜+备用格） | 每格标注映射到视频的时间段/用途 |

> `/生成` 阶段2 默认使用**分镜故事板模式**；用户要求"多角度底图/选首帧"时使用多机位底图模式。

---

## 2. 八要素（每格必须包含）

| # | 要素 | 说明 | 写法示例 |
|---|---|---|---|
| 1 | **景别** | 画面范围大小 | 大特写/特写/近景/中景/全景/远景 |
| 2 | **构图** | 主体位置+角度 | 居中/三分法/俯视45°/顶视90°/低角度仰视/对称 |
| 3 | **主体** | 核心对象+外观锁定 | 橙色运动饮料瓶（圆柱形/高饱和橙色液体/白色瓶盖/标签logo） |
| 4 | **高势能瞬间动态** | 未完成的动势，禁止静态描述 | 脚掌蹬地腾空瞬间/水花炸裂扩散中途/瓶盖炸开液体飞溅瞬间/喉结滚动饮用中途 |
| 5 | **场景** | 环境+背景 | 室内篮球场冷蓝灯光/纯黑背景/场边长椅/观众席虚化光斑 |
| 6 | **光源方向** | 定光源方向+类型 | 顶光+侧逆光双光源/窗边自然光/伦勃朗光/蝴蝶光/冷蓝球场顶光 |
| 7 | **材质/景深** | 物理反光+前后景分离 | 金属反光高光不过曝/极浅景深f/1.4背景虚化/磨砂质感/液体通透折射 |
| 8 | **视觉预设** | 整体风格词包 | 商业广告质感/电影感/日系清新/科技感/复古胶片/极简白底 |

> **🔴 高势能瞬间规则**：动态必须包含未完成的动势（"瞬间""中途""腾空""炸裂"），禁止静态描述（"放在桌上""站立""微笑"），为下游视频模型预留运动势能。

## 3. 六种风格预设（标准化词包）

| 预设 | 核心词包 | 适用场景 |
|---|---|---|
| **商业广告** | 商业广告质感，高饱和冷暖对比，产品级布光（主光+辅光+轮廓光+背景光），极浅景深，高光不过曝，8K超清 | 产品广告/品牌宣传片/电商主图 |
| **电影感** | 电影级写实，2.35:1宽屏感，伦勃朗光/侧光，胶片颗粒，浅景深，色彩分级（暖黄/冷蓝），高动态范围 | 剧情短片/电影分镜/人物叙事 |
| **日系清新** | 日系清新，过曝柔光，低饱和暖色调，自然光（窗边/户外），浅景深，柔和阴影，空气感 | 治愈系/生活方式/美妆护肤 |
| **科技感** | 科技感，冷蓝调，霓虹光/赛博朋克，金属/玻璃质感，极浅景深，高对比，未来感 | 数码产品/APP展示/科幻题材 |
| **复古胶片** | 复古胶片，胶片颗粒，暖黄/褪色色调，低对比，柔焦，自然光，怀旧感 | 复古题材/回忆录/文艺短片 |
| **极简白底** | 极简白底，纯白背景，柔和顶光，产品居中，无多余元素，干净阴影，高解析 | 产品白底图/电商主图/目录图 |

> 生成时选取一个预设作为【全局风格】，所有格子统一使用该预设词包，禁止跨格风格漂移。

## 4. 全局硬锁定模块（顶层锚点）

每组分镜图提示词必须包含以下全局锁定模块，放在九宫格内容之前：

```
【任务】九宫格 3×3，[多机位底图模式 / 分镜故事板模式]
【主体锁定】@图片1 (外观/材质/比例/Logo严格锁定，禁止改变设计)
【全局风格】[6大预设之一] + 统一主光源逻辑 + 景深分层标准
【交付约束】
  - 画质参数：8K, 商业摄影布光, 高光不过曝, 细网格物理隔离防渗透
  - 格间防渗透：3x3 Grid, separated by clean thin grid lines, distinct independent frames, no element bleeding across borders
  - 禁忌过滤：无文字水印UI, 无肢体畸变, 无主体形变, 无跨格渗色, 无真实品牌名
```

### 4.1 格间物理防渗透约束（强制）

> 🔴 必须在全局交付约束中加入：`3x3 Grid, separated by clean thin grid lines, distinct independent frames, no element bleeding across borders`

防止多格画面元素串味（如格1的水花溅到格2，格3的人物手臂伸到格4）。

### 4.2 主体锁定规则

- 产品类：形状+颜色+材质+logo位置+尺寸，明确"禁止AI改动设计"
- 人物类：性别+体型+发型+服装+五官特征，明确"不磨皮"
- 每格重复主体关键外观属性，不依赖全局锁定单独说明
- 液体/发色/服装颜色固定，标注"不偏移"

## 5. 下游视频映射标签（故事板模式专用）

分镜故事板模式中，每格末尾标注对应的下游视频用途：

```
格1：[景别] + [构图] + [主体] + [高势能瞬间动态] + [场景] + [光源方向] + [材质/景深] + [视觉预设] ➔ [映射: 视频0-3s首帧]
格2：... ➔ [映射: 视频3-5s过渡帧]
格3：... ➔ [映射: 视频5-8s核心视觉首帧]
...
```

**映射标签类型**：
- `[映射: 视频X-Ys首帧]` — 该格作为视频对应时间段的首帧参考
- `[映射: 视频X-Ys材质参考]` — 该格作为产品/人物材质/外观参考
- `[映射: 视频X-Ys场景参考]` — 该格作为场景/光影参考
- `[映射: 备用]` — 备用格，不直接映射

> 多机位底图模式不需要映射标签，标注"供选首帧"即可。

## 6. 分镜图专用 5 条质量门控

生成分镜图提示词后、交付前，必须逐条过以下 5 条门控：

### 门控 1：结构完整性

| 检查项 | 通过标准 |
|---|---|
| 全局模块齐全 | 任务+主体锁定+全局风格+交付约束 4段齐全 |
| 八要素齐全 | 每格包含景别+构图+主体+高势能动态+场景+光源+材质景深+视觉预设 |
| 格间防渗透 | 交付约束中包含防渗透英文约束句 |
| 映射标签（故事板模式） | 每格末尾有映射标签 |

### 门控 2：主体一致性

| 检查项 | 通过标准 |
|---|---|
| 外观锁定完整 | 主体锁定包含形状+颜色+材质+logo，明确"禁止改动设计" |
| 每格重复 | 每格画面描述中重复主体关键外观属性 |
| 颜色固定 | 液体/发色/服装颜色标注"固定/不偏移" |
| 无设计改动 | 全局和每格均无"AI可调整设计"类表述 |

### 门控 3：光影与景深统一

| 检查项 | 通过标准 |
|---|---|
| 风格预设统一 | 所有格使用同一个6大预设之一，无跨格风格漂移 |
| 光源方向合理 | 每格标注光源方向，同场景内光源方向一致 |
| 景深分层 | 每格标注景深（极浅/浅/中/大），前后景分离明确 |
| 高光控制 | 金属/液体/玻璃材质标注"高光不过曝" |

### 门控 4：多模态引用合规

| 检查项 | 通过标准 |
|---|---|
| 编号连续 | @图片1→@图片2 无跳号无重复 |
| 用途标注 | 每个 @媒体 标注"作为XX参考" |
| 主体参考 | 主体锁定段引用 @图片1 作为外观参考 |
| 数量合规 | 图片≤9，无视频/音频引用（分镜图不需要） |

### 门控 5：商业禁忌过滤

| 检查项 | 通过标准 |
|---|---|
| 无文字水印 | 全局禁忌包含"无文字水印UI" |
| 无畸变形变 | 全局禁忌包含"无肢体畸变/无主体形变" |
| 无跨格渗色 | 全局禁忌包含"无跨格渗色"+防渗透约束 |
| 无真实品牌名 | 用通用名替代（"运动饮料"而非"佳得乐"） |
| 高势能动态 | 每格动态包含未完成动势，无静态描述 |

## 8. 与视频提示词的衔接规则

| 维度 | 分镜图提示词（生图） | 视频提示词（生视频） |
|---|---|---|
| 动态 | 高势能瞬间（未完成动势） | 完整动作过程（时间轴+运镜+转场） |
| 时间 | 无时间轴，映射标签标注对应视频段 | 精确到秒的时间轴 |
| 运镜 | 不写运镜，写构图+机位 | 运镜（推拉摇移）+转场 |
| 声音 | 无声音 | 内嵌声音分层+ BGM总述 |
| 下游 | 映射标签指向视频时间段 | 引用分镜图作首帧/材质参考 |

> 分镜图的"高势能瞬间"是视频提示词对应时间段的"起始帧"，两者通过映射标签一一对应。

## 9. 使用规则

1. **模式选择**：`/生成` 阶段2 默认分镜故事板模式；用户要求多角度选首帧时用多机位底图模式
2. **八要素强制**：每格必须包含全部八要素，缺项视为不合格
3. **高势能动态强制**：禁止静态描述，必须包含未完成动势
4. **格间防渗透强制**：全局交付约束必须包含防渗透英文约束句
5. **风格预设统一**：所有格使用同一个6大预设，禁止跨格风格漂移
6. **主体锁定强制**：产品/人物外观锁定+每格重复+禁止改动设计
7. **5条门控强制**：交付前必须逐条过5条门控，附门控自检表
8. **映射标签（故事板模式）**：每格末尾标注下游视频映射用途
9. **🔴 中英双文强制输出**：分镜图提示词必须输出中英双文版，先中文后英文，分开输出不混排，每版独立完整块方便复制；英文版正文无中文字符残留，过语言一致性门控
