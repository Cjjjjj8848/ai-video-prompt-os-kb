# 电影导演分镜模板（templates/cinema）

> 电影级/高质感分镜模板，用于品牌片、故事片、高质感广告。

## 结构（30s 品牌片示例）

```
Act1 建立（0-8s）  环境/人物建立，情绪基调
Act2 冲突/发展（8-20s） 产品介入，卖点演绎，情绪推进
Act3 解决/升华（20-30s） 效果定格，品牌/CTA
```

## 分镜字段（每镜）

镜号 / 时间戳 / 景别 / 机位 / 运镜 / 画面 / 动作链 / 台词 / 音效 / 转场 / 情绪

## 示例片段

```
镜3(4-6s)  中景→特写 平视 缓慢推近
           主角在窗边，光线侧打入，拿起产品
           运镜：推近至产品特写
           转场：匹配剪辑 → 下一镜产品细节
           情绪：期待/安静
```

## 原则

- 三幕式叙事，情绪有起伏
- 电影手法适度用于品牌片，带货不强行电影化
- 光影/色调统一，浅景深营造电影感
