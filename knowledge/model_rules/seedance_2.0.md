# Seedance 2.0 提示词规范（model_rules）

> 投喂 Seedance 2.0 / 即梦等视频模型时的提示词规则。

## 1. 结构规范

```
【任务】时长 + 画幅 + 内容类型
【产品/主体】名称 + 外观锁定 + 卖点
【分镜】每镜：镜号(时间戳) 景别/机位/运镜/动作链/台词/音效/转场
【产品一致性】颜色/logo/材质固定描述
【光影】具体灯光方案
【声音】音效层级 + BGM
【模型指令】@参考图 + 负向提示词 + 首帧策略
```

## 2. 提示词要点

- 时间戳精确到秒：Shot1(0-3s)
- 动作描述具体可执行，禁止"自然流动"类空话
- 每镜一个主运镜，不堆叠
- 长视频超单段上限必须分段 + 丝滑衔接规则

## 3. 模型分层策略

- 简单品/静态演示 → 轻量模型，快且省
- 复杂动作/易穿模镜头 → 旗舰模型，逐镜控制
- 工具名不写死，只保留分层策略

## 4. 负向提示词通用项

模糊、畸形手指、过度油光、乱码文字、多余肢体、画面抖动
