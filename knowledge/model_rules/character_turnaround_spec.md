# 人物四视图规范（character_turnaround_spec.md）

> 角色一致性参考表（character turnaround / model sheet）的生成规范。属于**图像生成端**模板，作为视频/IP/电商模特角色的**前置锁定环节**：先在生图端锁死人物外观，再进入九宫格分镜 / Seedance 视频阶段，避免视频生成时人物跑偏。
> 对应 DNA：DNA-050（四竖栏分屏构图）/ DNA-051（--cref/--cw 锁脸）/ DNA-052（lookbook 视觉规则）。

---

## 1. 适用场景

- 影视/游戏角色设定（同一人物多视角参考）
- 服装 lookbook / 穿搭展示（正面/侧面/背面廓形）
- IP 形象建模参考（前/侧/背 + 脸部特写）
- 电商模特一致性（跨图保持同一模特脸）
- **后续生图/生视频前的外观锁定**（先出四视图，再以四视图为参考生成内容）

## 2. 四竖栏布局规范（DNA-050）

| 栏位 | 视角 | 内容要求 |
|---|---|---|
| 第1栏 | 脸部胸像特写（close-up portrait of the face） | 识别五官/发型/配饰，占画面主体 |
| 第2栏 | 全身正面（full-body front view） | 平视居中，看清服装正面廓形 |
| 第3栏 | 全身侧面（full-body side view） | 侧转90°，看清廓形厚度与垂坠 |
| 第4栏 | 全身背面（full-body back view） | 看清后颈/发髻/后背剪裁 |

- 画幅：单张横版 `--ar 16:9`，用均匀垂直分隔线切成四个等宽竖栏
- 每栏人物**垂直居中、头顶留呼吸空间、脚部接近栏底**
- 标准焦段平视机位，无畸变
- **信息分配 = 1栏脸部细节 : 3栏全身廓形**

## 3. 双场景决策流

```
开始
├─ 有参考图？ ── 是 ──> 场景 A：--cref [图] --cw 100 锁脸
│                        └─ 提示词短（外观交给参考图），只换 [参考图URL]
└─ 否 ──> 场景 B：纯文字锁特征
           ├─ 五官/痣/配饰/服装逐项写死
           └─ 强调 "All four panels must show the SAME person"（每栏重复锁定）
```

### 场景 A：有参考图（--cref 锁脸）

- 开头写双图引用：`脸部特写参考[URL]，全身参考[URL]`
- 声明"严格使用参考图中的同一人物 + 禁止改动任何特征"
- 参数：`--cref [图] --cw 100 --ar 16:9 --v 6.1`
- 锁脸强度调整：
  - `--cw 100`：最强锁脸，100% 保留参考人物面部（默认）
  - `--cw 75`：保留脸但允许服装/姿势一定变化（服装被改但脸要保留时）
  - `--cw 50`：更多自由度（不推荐用于四视图，容易跑偏）
- 脸仍跑偏时：保持 `--cw 100`，并在提示词中把五官特征**写死两遍**

### 场景 B：无参考图（文字锁特征）

- 识别特征必须**自包含**：年龄 / 肤色 / 发型（发色+造型+碎发）/ 五官（眉/眼/鼻/唇/痣）/ 配饰 / 服装（款式+颜色+材质）/ 鞋 / 身材比例
- 一致性强调句：`All four panels must show the SAME {person} — identical hairstyle, facial features, accessories, garment color and body proportions across all four panels`
- 不加 --cref/--cw 参数
- 风险最高：四栏易跑偏成四个人，特征描述越具体越好

## 4. 视觉规则（DNA-052 lookbook 定调）

默认亮白影棚 lookbook，可替换为其他风格：

| 要素 | 默认取值 |
|---|---|
| 背景 | 亮白/纯白影棚（bright white studio），干净无杂物 |
| 主光 | 柔和窗光（soft window sunlight），单侧大窗，光比小、阴影边缘柔化 |
| 层次 | 地面/墙面柔和窗格投影，增加层次但不抢主体 |
| 配色 | 单色系/低饱和高明度（如奶油色全套装） |
| 风格词 | high fashion lookbook, photorealistic, 8k |
| 材质强调 | 材质肌理（linen texture 等）+ 廓形（oversize draped silhouette 等） |

> 关键：不是硬打光白底证件照，而是有生活感的自然窗光 + 地面软投影。

## 5. 与其他环节的衔接

```
[前置] 人物四视图（本规范）→ 锁定人物外观（脸/发型/配饰/服装/比例）
   ↓
[中段] 九宫格分镜图（storyboard_prompt_spec.md）→ 每格引用四视图锁定的人物
   ↓
[后段] Seedance 视频提示词（quality_gate_checklist.md）→ 一致性锁定沿用
```

- 四视图生成的图片可作为后续九宫格/视频的 `@图片` 参考
- 视频提示词的人物外观描述必须与四视图一致（继承 DNA-022 一致性锁定三段式）

## 6. 四视图专用 4 条质量门控（输出前必须逐条过）

| 门控 | 检查项 |
|---|---|
| 门控1 布局完整性 | 单张 16:9、四等宽竖栏、栏位顺序（脸部/正面/侧面/背面）、无跨栏渗色、分隔线清晰 |
| 门控2 主体一致性 | 四栏同一人：发型/五官/痣/配饰/服装颜色/身材比例逐项核对；有图场景 --cw=100，无图场景特征自包含 + "same across all panels" 强调 |
| 门控3 视觉统一 | 背景/主光/风格词四栏统一（默认 lookbook 规则），材质肌理与廓形一致 |
| 门控4 商业与语言合规 | 无文字水印/真实品牌名；中英双文版分开输出（先中后英），英文版无中文字符残留 |

## 7. 常见翻车与修正

| 翻车现象 | 修正手段 |
|---|---|
| 四栏变四个人 | 无图场景特征写死 + 一致性强调句；有图场景确认 --cw=100 |
| 服装被 AI 改款 | 有图降到 --cw 75 保脸换装；无图把服装款式/颜色/材质写死两遍 |
| 脸跑偏 | 保持 --cw 100，五官特征写死两遍；或重抽第1栏后整体参考 |
| 侧面/背面与正面不一致 | 强调 "same across all four panels"，补背面特征（发髻/后背剪裁）描述 |
| 栏位比例失衡 | 明确"1栏脸部:3栏全身"分配 + 每栏垂直居中 |
