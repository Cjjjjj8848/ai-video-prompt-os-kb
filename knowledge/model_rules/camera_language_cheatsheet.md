### 运镜组合规则

- **每镜只一种主运镜**，不堆叠"推拉摇移"
- **极速运镜后必须接静止镜头**形成反差（缓→急→静→缓）
- **转场处运镜方向保持连贯**（运动方向一致更顺滑）
- **简单品少运镜**靠画面本身，**复杂品用运镜**带出结构

## 2. 景别速查表

| 景别 | 写法 | 画面范围 | 用途 |
|---|---|---|---|
| 大远景 | 大远景 / 极远景 | 环境全貌，人占画面<10% | 建立场景、氛围 |
| 远景 | 远景 | 人物全身+环境 | 场景建立、人物定位 |
| 全景 | 全景 / 全身 | 人物全身，环境占比减少 | 人物动作、整体展示 |
| 中景 | 中景 / 半身 | 人物腰部以上 | 对话、互动、产品使用 |
| 近景 | 近景 / 胸部以上 | 人物胸部以上 | 表情、情绪、产品细节 |
| 特写 | 特写 / 微距 | 局部（脸/手/产品细节） | 强调细节、情绪、质感 |
| 大特写 | 大特写 / 极近特写 | 极小局部（眼睛/嘴唇/logo） | 极致强调、钩子 |

### 景别递进规则

- 标准递进：远景→全景→中景→近景→特写（由远及近，聚焦）
- 反转递进：特写→近景→中景→全景→远景（由近及远，释放）
- 跳级衔接：相邻镜头景别差≥2级时，用运镜或转场掩盖跳跃感
- 产品展示：全景（整体）→中景（使用）→特写（细节）→全景（落版）

## 7. 提示词组装公式（内聚化格式）

> ⚠️ **内聚化规则**：【声音】必须内嵌到对应【时间轴分镜】下方，禁止将所有声音集中放在时间轴之后的独立大块。多场景切换处必须标注转场方式。

```
【风格】{质感关键词} + {色调关键词} + {情绪关键词}，{时长}秒，{画幅}比例

【时间轴】
0-X秒：[{景别}] [{运镜}]，[{机位}]，{画面内容}，{主体动作}，{光影}
  └─ 转场：{硬切/匹配剪辑/甩镜/叠化/能量转场}（多场景切换处必填）
  └─ 声音：[时间段] {动作音} + [时间段] {情绪音} + {对白}
X-Y秒：[{景别}] [{运镜}]，[{机位}]，{画面内容}，{主体动作}，{光影}
  └─ 转场：{转场方式}
  └─ 声音：[时间段] {动作音} + [时间段] {情绪音} + {对白}

【BGM总述】{配乐风格}，{BPM}，情绪曲线：{压抑→爆发→高潮→收束}
【参考】@图片1 {用途}，@视频1 {用途}，@音频1 {用途}
【画质要求】{分辨率}，{光影方案}，{景深}，{质感}，{运动模糊}
【一致性锁定】严格还原参考图{对象}，不做{禁止项}，保持{保持项}
【禁忌】无{画面禁忌}，无{人物/物体禁忌}
```

### 内聚化格式说明

1. **声音内嵌**：每个分镜下方用 `└─ 声音：` 标注该镜的动作音/情绪音/对白，减少 AI 长距离上下文匹配衰减
2. **转场显性化**：多场景切换处（写实→纯黑→特效等）用 `└─ 转场：` 明确标注切镜方式，避免过渡生硬
3. **BGM 总述独立**：整体配乐风格放在时间轴之后，不拆散到每镜
4. **单场景短镜**：如果相邻两镜同场景且无特殊转场，可省略 `└─ 转场：` 行（默认硬切）

### 组装示例（磁吸充电宝 · 内聚化格式）


## 8. 使用规则

1. **查表调用**：生成提示词时，从本表直接选取标准写法，不用临场造词
2. **每镜必含**：景别 + 运镜 + 机位 + 画面 + 动作 + 光影（6 要素）
3. **不堆叠**：每镜只一种主运镜，光影只选 1-2 个关键词
4. **前后连贯**：相邻镜头的景别、运镜方向、光影要考虑连贯性
5. **🔴 声音内聚化**：【声音】必须内嵌到对应分镜下方（`└─ 声音：`），禁止集中放在时间轴之后的独立大块
6. **🔴 转场显性化**：多场景切换处必须标注转场方式（`└─ 转场：`），单场景同景别相邻镜可省略（默认硬切）
7. **商业兜底**：无论选什么艺术表达，【画质要求】+【一致性锁定】+【禁忌】三段必须保留
