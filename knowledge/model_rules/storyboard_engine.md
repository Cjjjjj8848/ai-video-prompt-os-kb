# 分镜决策引擎（V6 核心 · 替代强制九宫格）

> 来源：小墨分镜 v6.0 + 用户 V5.4 实战反馈。解决"九宫格强制 9 格导致多场景装不下、格间硬隔离杀死转场流畅度"的问题。
> 本文件是 L1-L4 四档共用的分镜引擎，档位开关见 `type_routing.md`。

## §1 场景锚点地图（每场景必建）

**问题**：AI 跨镜跑偏，根因是方位词没绑锚点（"左边""旁边"没参照物）。

**做法**：分镜前先为每个场景建一张锚点表，后续所有镜头的方位描述必须绑锚点名。

### 锚点三类

| 锚点类型 | 例子 | 作用 |
|---|---|---|
| **光源锚点** | 大窗户（朝西 16:00）/ 床头台灯 / 圣诞树暖灯 / 顶灯 | 光线来源，所有镜头必须交代光从哪个锚点来 |
| **家具/道具锚点** | 床头柜 / 收银台 / 铁艺栏杆 / 车座 | 人物站位参照 |
| **通道锚点** | 入户门 / 便利店出口 / 走廊 | 人物移动路径 |

### 锚点地图输出格式

```
【场景：便利店收银区】
- 光源锚点：顶部荧光灯（冷白）、收银台后小台灯（暖黄，小丑脸主光）
- 家具锚点：收银台（横向，高 1.1m）、POS 终端（台面右侧）、玩具枪架（柜台下）
- 通道锚点：便利店门（画面左侧）、收银台后员工通道（画面右侧）
- 空间类型：S2 室内中型（见 §2）
```

### 铁律

- ❌ 禁止"左边的人""旁边的杯子""远处"——必须写成"收银台右侧的 POS 终端""门口进来的手"
- ✅ 人物移动必须写路径："手从画面左侧（门口）伸到收银台右侧（POS 机）"
- 换场景就重建一张锚点地图，不复用旧锚点

## §2 空间物理矩阵（先判空间，再定镜头）

**优先级**：物理可行性 > 叙事情绪 > 多样性指标。冲突时物理先行。

### 7 类空间

| 代号 | 类型 | 物理特征 | 最大景别 | 鸟瞰 | 升降 |
|---|---|---|---|---|---|
| S1 | 室内小空间 ≤20㎡ | 卧室/书房/卫生间/小厨房/车厢内 | 全景 | ❌ | ❌ |
| S2 | 室内中空间 20-60㎡ | 普通客厅/会议室/教室/酒店客房/小店铺 | 全景（远景区慎用） | ❌ | ❌ |
| S3 | 室内大空间 60-200㎡ | 大客厅/宴会厅/教堂中殿/商场中庭 | 远景 | ⚠️ 层高≥5m | ⚠️ 层高≥4m |
| S4 | 室内超大 >200㎡ | 机场大厅/大教堂/体育馆/火车站 | 大远景 | ✅ | ✅ |
| O1 | 室外开阔 | 街道/广场/原野/海面/山脉 | 大远景 | ✅ | ✅ |
| O2 | 室外半封闭 | 小巷/庭院/天井/回廊/露台 | 远景 | ⚠️ | ⚠️ |
| X | 特殊封闭 | 车内/电梯/楼梯间/隧道/电话亭 | 中全景 | ❌ | ❌ |

### 焦段-空间红线

- S1/S2 室内：超广角 <24mm 慎用（墙壁畸变），长焦 >135mm 禁用（退不开）
- X 车内：最大中全景，禁止横移/拉镜/轨道/环绕/滑动变焦
- 任何室内：鸟瞰要求镜头在场景正上方 3m+，普通层高 <3m 禁止鸟瞰，用 30-60° 高角度俯拍代替

### 12 条物理不可能镜头（出现即废）

1. S1/S2 室内用大远景/远景
2. S1/S2/S3（层高<5m）用鸟瞰
3. S1/S2 室内用升降
4. S1/S2 室内用摇臂
5. S1 室内小空间用长焦 >135mm
6. S1/S2 用超广角 <24mm 拍人物近景
7. X 特殊封闭用大远景/全景
8. X 用横移/拉镜/轨道/升降/环绕/滑动变焦
9. 固定镜头同时描述"镜头环绕主体"（自相矛盾）
10. 室内出现无来源光线（光必须绑光源锚点）
11. 拉镜/环绕未确认机位背后有退让空间
12. X 场景用过肩（机位退不到人物背后 1.5m）

## §3 重技法频率上限（防止炫技）

以下"重锤"技法用多了廉价化，每片严格守上限：

| 重技法 | 全片上限 | 使用门槛 |
|---|---|---|
| Dolly Zoom 滑动变焦 | ≤1 | 必须有"认知崩塌"瞬间 |
| Orbit 环绕 | ≤3 | 必须有"主体崇拜/关系揭示/时间凝固"理由 |
| 长镜头一镜到底 | ≤2 | 必须有"情绪累积沉浸"段落 |
| 鱼眼 | ≤2 | 必须有"癫狂/迷幻"瞬间 |
| 荷兰角 | ≤4 | 必须有"失衡/悬疑"情绪点 |
| 升降 Crane | ≤2 | 必须有"史诗揭示"+ 场景物理允许 |
| POV 主观视角 | ≤3 | 必须有"角色第一次发现/震撼"瞬间 |
| Snorricam | ≤1 | 必须有"主观失衡/恐慌" |

**三重确认**：每个重技法镜头必须写明 ①叙事理由 ②是否本场景重锤瞬间 ③次数未超上限。没有重锤瞬间就用基础运镜（推/拉/摇/手持/跟拍/固定），不上重技法。

**固定镜头比例**：全片固定镜头 ≤30%，连续 3 个固定镜头必须改运动镜头。

## §4 情绪曲线 + 钩子五级

### 情绪节奏曲线（分镜前必画）

标每个情绪节点：类型（紧张/温情/悲伤/震撼…）+ 强度 1-10 + 持续度。

- 上升段：镜头变紧、运镜变快、景别递进
- 爆发点：重锤镜头（推镜/拉镜/特写/反规则）
- 平复段：镜头变松、运镜变慢、留白空镜
- 沉默段：固定镜头或环境空镜

**L2 广告简化版情绪曲线**：钩子(0-3s 强钩) → 痛点/悬念(3-15s) → 产品救场(高潮点) → CTA 尾(3-5s)。

### 钩子五级

| 级 | 类型 | 例子 | 强度 |
|---|---|---|---|
| L1 | 好奇心 | 门口出现无寄件人包裹 | 弱，易忘 |
| L2 | 担忧 | 角色不知道房间有人，但观众看到了 | 中 |
| L3 | 选择 | 手指在两个电话名之间游移 | 强，选择定义角色 |
| L4 | 认知颠覆 | 刚认定是盟友的人，最后一镜暗示他有自己计划 | 极强 |
| L5 | 情感卷入 | 孩子把最重要的话说给听不见的人 | 无法抗拒 |

**规则**：L1/L2 前 3s 钩子必须 ≥L3；L3/L4 关键转折用；L4 每集尾钩 ≥L3。

### 情绪-镜头反规则（基础规则之外的更有力选项）

| 情境 | 基础规则 | 反规则 |
|---|---|---|
| 悲伤/绝望爆发 | 推到特写 | 反而拉远，人物在环境中渺小 |
| 震撼/认知崩塌 | 推镜逼近 | 反而固定大特写，无处可逃 |
| 暴力/冲击 | 直接展示 | 切空镜或拉远，留白让观众脑补 |
| 孤独/被遗弃 | 特写表情 | 大景别人物居中，环境包围 |
| 阴险反派 | 仰拍威严 | 平视或微仰，近在咫尺的威胁 |
| 争吵升级 | 越吵越紧 | 反而拉远看两人对峙全貌 |

## §5 反廉价化三层（画质保险）

### Tier A 通用核（所有镜头必带）

避免：塑料感/CG 渲染/游戏引擎质感、AI 式诡异对称、畸形或多指手、数字过度锐化、无光源动机的全局均匀补光、无物理依据的全局雾。每处亮度必须有来源、方向、真实衰减。

有人物时追加：避免蜡质皮肤/美颜磨皮，保留真实毛孔、瑕疵、次表面散射。

### Tier B 题材桶（按题材选一）

- **G1 冷峻纪实/正剧**：低饱和克制；避免失控 HDR、广告级鲜艳、浮夸镜头光效
- **G3 胶片诗意/浪漫**：放行暖调 halation、柔和光斑、轻微光学畸变；避免数字锐利
- **G4 霓虹/高对比发光**：放行高饱和彩色光溢出与 halation；避免均匀提亮暗部
- **G6 恐怖/惊悚**：放行大面积欠曝、死黑、低饱和；避免为可见度补光
- **G7 动作大片**：放行胶片颗粒、暖怀旧调、深阴影；避免合成感光照

**题材签名优先**：Tier B 与 Tier A 冲突时，Tier B 优先（如 G4 放行高饱和，不受通用"避免过饱和"约束）。

### Tier C 中文表达（融入【画质要求】段）

- 光源层面：禁用无来源光/无动机补光；有签名时写"放行：{项}"
- 风格层面：按 Tier B 题材条款写
- 造型层面：无塑料光泽、无 CG 感、无数字锐化

### 软化预算检查

grain/halation/雾/diffusion/bloom 最多 2 项全开，其余降为 subtle 或省略。物理雾双检：场景同时有可见介质（烟/尘/蒸汽/雪）+ 具名光源时才写体积光，否则用"光/曝光分离"或"遮挡递退"做纵深。

## §6 衔接四件套（跨镜连贯）

### 180° 轴线
对话/对峙场景，机位始终在两人连线同一侧。A 看右→B 必须在画面左。越轴需显式理由（精神错乱/环绕越轴/中性镜头过渡）。

### 30° 规则
同一主体相邻两镜，机位角度差 ≥30°，或焦段显著变化，否则跳切。

### 景别跳跃
相邻两镜景别差 ≤3 级。>3 级必须插过渡镜或用动作/视线/图形匹配。大景别直接切大特写必须标注"刻意跳切"+强烈叙事理由。

### 视线匹配
A 看画面右 → 下一镜 B 在画面左；A 看画外 → 下一镜切到该物特写。

### 跨段衔接表（段间必查）

| 检查项 | 段1→段2 | 段2→段3 |
|---|---|---|
| 人物位置一致 | ✅/❌ | |
| 场景光线连续 | ✅/❌ | |
| 色调方案统一 | ✅/❌ | |
| 情绪衔接自然 | ✅/❌ | |
| 接续关键点匹配 | ✅/❌ | |
| 渲染技术连续 | ✅/❌ | |

## §7 逐镜头关键帧卡片（替代九宫格）

**不再强制 3×3 九格。** 镜头数随剧情走：L1 3-6 镜、L2 5-10 镜、L3 视时长。每镜一张卡片。

### 卡片模板

```
### 镜头 0X | 空间类型 S?/O?/X | 时长 X.Xs

【景别】大远景/远景/全景/中景/中近景/近景/特写/大特写
【机位】平视/仰拍/俯拍/鸟瞰/荷兰角/过肩/POV（标注情绪目的；反规则时写⚠️反规则）
【运镜】固定/推/拉/横移/跟拍/摇/手持/环绕/升降（重技法标注"全片第X次/上限X"）
【主体动态】高势能瞬间：正在进行的动作（"正把充电宝啪地吸到手机背面"），禁止静态摆拍
【锚点绑定】人物从{通道锚点}移动到{家具锚点}，光从{光源锚点}来
【画面内容】看图说话：谁在哪做什么，非人物镜头标注"无人物面部入镜"
【台词/口播】说话人："……" / 无 / 画外音延续
【声音】环境音 + 动作音 + 情绪音（精确到秒）
【转场】与上镜的衔接方式（动作匹配/视线匹配/硬切/音桥/视桥）
【映射下游】→ 视频 X-Ys 首帧 / 材质参考 / 场景参考 / 备用
```

### 卡片设计顺序

1. 先判空间类型（§2）
2. 再选景别+机位+运镜（受空间物理约束）
3. 写锚点绑定（§1）
4. 写高势能动态
5. 标台词声音
6. 标与上镜衔接
7. 重技法过频率自检（§3）
8. 跨段打衔接表（§6）

### 输出形式

- 关键帧提示词：每镜一张图（不拼九宫格），单独输出提示词
- 中英双文，先中后英分开
- 用途：生图模型出单张关键帧 → 作为视频模型首帧/参考
