# 六层人物档案与关系张力矩阵

## 六层模型

### L1 表面欲望（Surface Want）
角色以为他想要什么。必须具体、可见、可度量。角色自己可以明确说出。
例："我要拿到那笔钱" / "我要让她爱上我" / "我要复仇"

### L2 深层需求（Deep Need）
角色真正需要什么才能完整。往往与表面欲望冲突。角色自己意识不到或拒绝承认。
例：表面要钱，深层需要被尊重；表面要复仇，深层需要放下。

**关键**：表面欲望和深层需求必须产生张力。角色越追表面，离深层越远——直到崩溃点。

### L3 执念/谎言（The Lie They Believe）
角色相信的关于自己或世界的错误信条。这是角色的操作系统。
例："我不值得被爱" / "世界是零和博弈" / "只要够强就不会受伤"

**好的谎言不是"错的"——它曾经正确过，在某个阶段保护过角色。**

### L4 阴影/幽灵（The Ghost）
过去的具体创伤，创造了谎言。必须是一个具体可描述的时刻。
不是"童年不幸"，而是"七岁那年母亲当着他的面撕掉了他画了三天的画"。
幽灵要能在故事中以某种形式重现（意象/对白/情境）。

### L5 伤口（The Wound）
幽灵诞生的瞬间的精确感受。外部事件+内部解释。
关键：角色对事件的解释 ≠ 客观真相。

### L6 面具（The Mask）
角色向世界呈现的形象，与真实自己的差距。面具是防御机制。
最佳设计：面具在故事中逐渐出现裂缝，真实自己从裂缝中漏出。

## 人物档案模板

```
【角色名】
- 表面欲望：
- 深层需求：
- 执念/谎言：
- 阴影/幽灵（具体时刻）：
- 伤口（外部事件+内部解释）：
- 面具：
- 内在矛盾（两个互斥身份共存）：
- 秘密（从未告诉任何人）：
- 不可逾越的底线……直到被逾越的那一刻：
- 愿意为之死的人/愿意为之杀的人：
```

## 关系张力矩阵

每对核心人物定义：
1. **公共关系**：外人眼中他们的关系
2. **私人关系**：实际上他们之间发生了什么
3. **秘密关系**：各自对这段关系的真实感受（可能彼此不知道）
4. **转折点**：这段关系在故事中的关键转折

**关系类型警示**：避免单功能关系。导师-学生要互相改变；爱人要加权力不对等；仇敌要互相尊重（理解不代表原谅）。

## 商业片调用规则（轨道A）

广告片人物不需要完整六层（达人不是创伤患者），但**面具与裂缝**必须调用：
- 人物开场的"面具"是什么（平庸/压抑/狼狈）
- 产品介入后"裂缝"出现在哪里（微表情变化/眼神转变）
- 终点面具如何改变或摘下

**这解决AI假笑/手乱晃的核心**：给人物明确的心理发力点，而不是"对着镜头笑"。
