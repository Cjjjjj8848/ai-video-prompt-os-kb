# 声音设计库（audio）

> BGM / 音效 / 口播节奏 DNA。

## 1. 音效层级

- 环境音：场景底噪（室内/户外/街道）
- 产品音效：开盖/旋出/按压/撕膜（ASMR 关键）
- 动作音效：脚步、碰撞、翻页
- 界面音效：提示音、打字声

## 2. BGM 选型

| 风格 | 适用 |
|---|---|
| 轻快流行 | 快节奏带货、TikTok |
| 舒缓治愈 | 美妆、疗愈、开箱 |
| 科技感 | 数码、智能产品 |
| 复古/国风 | 特定人群或品类 |

## 3. 口播节奏

- 前 3 秒台词必须与钩子画面同步出现
- 卖点台词在演示段对应画面出现，不提前不滞后
- 台词用目标市场语言，附中文释义
- CTA 台词在最后 1-2s，简洁直接

## 4. 规则

- ASMR 沉浸：产品音效突出，弱化 BGM
- 带货不追求复杂混音，音效与画面动作一一对应

## 5. 精确到秒的三层音效时间轴（DNA-020，来自 case_001）

每镜音效必须标注精确时间区间，分三层并行：

```
[0.0s-1.5s] {动作音：关机滴滴声}
[1.5s-2.5s] {情绪音：轻喜剧悬疑低音推入}
{对白："Oh come on... 1% right now?!"}
```

**三层结构**：
| 层级 | 内容 | 示例 |
|---|---|---|
| 动作音 | 产品/物体发出的声音 | 关机滴滴、磁吸啪嗒、iOS充电提示、POS嘟嘟 |
| 情绪音 | BGM/氛围音，驱动情绪 | 悬疑低音（紧张）、欢快庆祝音乐（释放） |
| 对白 | 人物台词/口播 | 口语化情绪反应句 + 产品植入 + CTA |

**声音桥转场**：
- 前一镜结尾的音效（如悬疑低音）延续到后一镜开头，掩盖剪辑点
- 甩镜转场时用"呼啸声+风声"连贯两镜
- 情绪反转点用"卡点重音"标记（如玩具枪喷出彩带的瞬间）

**规则**：
- 每镜必须有 `[时间戳] 音效描述`，时间精确到 0.5s
- 产品动作必须配 ASMR 级细节音效，不可只写"音效"
- 情绪音必须与情绪曲线同步：紧张时低音，释放时欢快
- 对白不超过 6 句/全片，每镜 1-2 句
