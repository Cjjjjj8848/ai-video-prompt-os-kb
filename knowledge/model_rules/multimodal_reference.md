# 多模态引用语法规范（model_rules）

> 统一 @图片 / @视频 / @音频 的引用语法，让多模态素材从"玄学"变成"精确工程"。整合外部仓库规范 + V5 商业约束。

## 1. 核心原则

- **素材前置**：在提示词开头或【参考】段落明确列出所有素材及用途
- **一材一用**：每个 @素材 只承担一个主要用途，不混用
- **编号固定**：全程使用同一编号，不中途更换
- **用途明确**：每个引用必须说明"作为什么"（首帧/尾帧/角色/场景/运镜/配乐等）

---

## 2. 引用语法标准

### 基础格式

```
@素材编号 作为{用途}，{补充说明}
```

### 图片引用（@图片）

| 用途 | 标准写法 | 说明 |
|---|---|---|
| 首帧 | `@图片1 作为首帧` | 视频第一帧画面，决定开场 |
| 尾帧 | `@图片2 作为尾帧` | 视频最后一帧画面，决定落版 |
| 角色形象 | `@图片3 作为角色形象参考` | 人物五官/服装/造型，跨镜保持一致 |
| 产品外观 | `@图片4 作为产品外观参考` | 产品颜色/形状/logo/材质，禁止改动 |
| 场景参考 | `@图片5 作为场景参考` | 环境/布景/灯光氛围 |
| 材质参考 | `@图片6 作为材质参考` | 特定材质质感（金属/磨砂/液体等） |
| 分镜图 | `@图片7-9 作为分镜图参考` | 九宫格分镜图，按顺序对应各镜头 |
| UI 界面 | `@图片10 作为UI界面参考` | 产品界面/截图 |

### 视频引用（@视频）

| 用途 | 标准写法 | 说明 |
|---|---|---|
| 运镜参考 | `@视频1 参考运镜方式` | 模仿参考视频的镜头运动 |
| 动作参考 | `@视频2 参考动作节奏` | 模仿参考视频的主体动作 |
| 视频延长 | `将@视频3 延长X秒` | 基于已有视频续拍，生成长度选新增部分时长 |
| 视频编辑 | `基于@视频4 进行编辑` | 修改已有视频的特定部分 |
| 风格参考 | `@视频5 参考整体风格` | 模仿参考视频的视觉风格和节奏 |

### 音频引用（@音频）

| 用途 | 标准写法 | 说明 |
|---|---|---|
| 配乐 | `@音频1 用于配乐` | 背景音乐，画面切换与节奏同步 |
| 对白 | `@音频2 用于对白参考` | 人物说话内容，自动对口型 |
| 音效 | `@音频3 用于音效` | 特定音效（环境音/动作音） |
| 口播 | `@音频4 作为口播内容` | 口播视频，生成对口型说话画面 |

---

## 3. 素材数量限制

| 素材类型 | 最大数量 | 总时长限制 | 说明 |
|---|---|---|---|
| 图片 | ≤ 9 张 | — | 首帧/尾帧/角色/场景/分镜图等 |
| 视频 | ≤ 3 个 | 每个 ≤ 15s | 运镜/动作/延长/编辑参考 |
| 音频 | ≤ 3 个 | 每个 ≤ 15s | 配乐/对白/音效/口播 |
| **总计** | **≤ 12 个文件** | — | 图片+视频+音频总数不超过 12 |

> ⚠️ 视频参考会消耗更多额度，简单场景优先用图片参考。

## 4. 引用位置规范

### 方式一：集中在【参考】段落（推荐）

```
【参考】
@图片1 作为首帧
@图片2 作为角色形象参考
@图片3 作为产品外观参考
@视频1 参考运镜方式
@音频1 用于配乐
```

### 方式二：在时间轴内逐镜引用

```
【时间轴】
0-3秒：[中景] [推镜头]，@图片1 作为首帧，人物走入场景
3-7秒：[特写] [环绕]，@图片2 作为产品外观参考，展示产品细节
7-10秒：[全景] [拉远]，@音频1 配乐高潮，画面落版
```

### 方式三：混合使用（复杂场景）

- 【参考】段落列出所有素材总览
- 时间轴内在具体镜头处引用对应素材

## 5. 特殊场景引用规范

### 5.1 角色一致性

```
@图片1 作为角色形象参考，全程保持五官/服装/发型一致
```

- 有角色的视频必须提供角色参考图
- 角色每次出镜都要在该镜描述中重复 `@图片1`
- ⚠️ 暂不支持写实真人脸部素材，建议用风格化形象或"Figure 1"替代

### 5.2 产品一致性

```
@图片2 作为产品外观参考，颜色{色值}、logo位置、材质{磨砂/亮面}固定，不改变设计
```

- 产品每次出镜必须引用同一张产品参考图
- 在【一致性锁定】段落重复产品外观描述
- 多角度展示时，每个角度各用一张参考图：`@图片2 正面`、`@图片3 背面`

### 5.3 运镜复刻

```
完全参考@视频1的所有运镜效果，包括推/拉/摇/移的速度和节奏
```

- 需要精确复刻运镜时，用"完全参考"而非"参考"
- 在时间轴每镜标注对应参考视频的时间段

### 5.4 视频延长

```
将@视频1 延长10秒（生成长度选择10秒）
延续前视频的风格和主体：
0-3秒：{新增内容描述}
3-7秒：{新增内容描述}
7-10秒：{新增内容描述}
【要求】保持角色一致性，动作连贯流畅，与前视频无缝衔接
```

- 生成长度必须选择"新增部分"的时长，不是总时长
- 明确说明"延续前视频的风格和主体"

### 5.5 视频编辑/剧情颠覆

```
基于@视频1 进行编辑：
【保留】原视频的{运镜/场景/部分动作}
【修改】{具体修改点1}
【修改】{具体修改点2}
【颠覆】{剧情反转描述}
【要求】保持镜头连贯，只在指定位置修改
```

- 清晰区分"保留/修改/颠覆/新增"
- 每个修改点标注具体时间位置

### 5.6 音乐卡点

```
将@图片1-5 依次按顺序卡入@音频1的卡点中
【要求】画面切换与音乐重拍同步，转场自然流畅
```

- 提供音频参考，时间轴标注与音乐重拍对齐
- 图片顺序明确：`@图片1 → @图片2 → @图片3`

### 5.7 口播视频

```
使用@图片1的人物和环境，使用@音频1作为人物的声音内容，生成口播视频
【功能】自动生成对口型说话画面，支持情感调整（激动/平静/悲伤）
【要求】保持人物和声音跨镜头一致性，适当加字幕
```

- 人物形象图 + 语音音频必须同时提供
- 明确情感表现要求

## 6. 版权规避规范

| 风险 | 错误写法 | 正确写法 |
|---|---|---|
| 知名角色 | "生成哈利波特" | "Figure 1，戴圆框眼镜的黑发少年，穿黑色巫师长袍" |
| 真人脸部 | 真人照片作为参考 | 风格化形象 / 卡通形象 / "Figure 1" |
| 品牌 logo | 直接写品牌名 | 描述外观特征，不出现品牌名 |
| 受版权保护的音乐 | 具体歌曲名 | 描述风格："轻快流行电子乐" |

> 规则：不直接写角色名字，用 "Figure 1"、"Figure 2" 替代，描述外观特征。

## 7. 引用自检清单

生成提示词后，逐项检查：

- [ ] 所有 @素材 都有明确用途说明（"作为什么"）
- [ ] 素材编号全程一致，不中途更换
- [ ] 图片 ≤ 9 张，视频 ≤ 3 个，音频 ≤ 3 个，总计 ≤ 12 个
- [ ] 角色/产品每次出镜都重复引用对应参考图
- [ ] 视频延长时生成长度选"新增部分"而非总时长
- [ ] 视频编辑时清晰区分"保留/修改/颠覆/新增"
- [ ] 知名角色用 "Figure 1" 替代，不直接写名字
- [ ] 【一致性锁定】段落重复了关键素材的外观描述
- [ ] 音乐卡点时时间轴与重拍对齐
