# 转场与衔接库（transition）

> 段内转场 DNA。V5 融合基线。

## 1. 常用转场

| 转场 | 做法 | 适用 |
|---|---|---|
| 匹配剪辑 | 上一镜运动/形状与下一镜衔接 | 产品与使用场景切换 |
| 物体遮挡 | 物体扫过镜头完成过渡 | 展示型视频 |
| 甩镜/快速摇镜 | 动势掩盖剪辑点 | 快节奏带货 |
| 闪白/闪黑 | 情绪切换、时间跳跃 | 前后对比 |
| 缩放/推拉 | 从局部到整体 | 产品亮相 |
| 无转场硬切 | 景别/机位差异足够时直接切 | 高频节奏 |

## 2. 转场使用原则

- 转场处运镜方向保持连贯（运动方向一致更顺滑）
- 简单品少转场、靠画面本身；复杂品用转场带出结构
- 每镜一种主运镜，避免"推拉摇移"堆叠
- 转场服务于节奏，不为花哨而加

## 甩镜转场+声音桥组合（DNA-018，来自 case_001）

POV 视频最自然的视角切换方式：

**做法**：
1. 前一镜结尾做 Whip-tilt Down（极速下甩），带自然运动模糊
2. 同时播放"呼啸声+风声"连贯两镜
3. 后一镜开头突然平稳定格（Locked-off），视角已切换
4. 前一镜结尾的情绪音（如悬疑低音）延续到后一镜开头（声音桥）

**为什么有效**：
- 运动模糊掩盖剪辑点，观众感觉是连续动作而非切换
- 声音桥让听觉连续，进一步掩盖剪辑
- 甩镜后的突然静止形成反差，增强下一镜冲击力

**适用场景**：
- POV 第一人称视频的视角切换
- 从"看别人"切换到"看自己的手"（如充电宝案例从仰视小丑切换到俯拍手部）
- 长视频分段拼接
- 快节奏短视频的镜间过渡

## 4. 动作匹配+方向连贯转场（DNA-031，来自双视频蒸馏）

最自然的无缝转场方式——用主体动作的连续性和运动方向的连贯性掩盖剪辑点：

**做法**：
1. 前一镜结尾的主体动作与后一镜开头的动作完全匹配（起飞→飞行、走到→跑、弯腰→站直）
2. 所有镜头保持同一运动方向（全部右向运动惯性），禁止运动方向相反的硬切
3. 无硬切、无淡入淡出、无特效转场，全部通过主体动作和方向的连续性实现转场
4. 转场处的主体在画面中的位置保持一致（如都在画面左1/3）

**为什么有效**：
- 观众的视觉注意力跟随主体动作，动作连续时大脑会自动补全中间的剪辑点
- 运动方向连贯产生"惯性感"，观众感觉是一个连续的长镜头而非多个镜头
- 不需要任何特效，最自然、最电影化的转场方式

**适用场景**：第一人称叙事、连续动作类视频、追逐逃亡类视频、任何需要"无缝感"的多镜头视频。

## 5. 光作为媒介转场（DNA-032，来自双视频蒸馏）

用光线作为转场媒介，有两种经典用法：

**用法A：明暗对比转场（从外部进入内部）**
1. 前一镜：主体在明亮的外部空间，向一个黑暗入口（洞口/门口/巢穴入口）移动
2. 转场动作：主体"穿过入口"，画面从四周向中心收窄（模拟进入空间的光线变化）
3. 后一镜：内部较暗空间，光线从缝隙透入，画面再展开
4. 光线变化：由亮到暗的自然过渡，观众感觉"跟着主体一起进去了"

**用法B：火光匹配转场（从灾难转到产品）**
1. 前一镜结尾：画面被火焰/强光充满（过曝到白色/橙色）
2. 转场：从强光中淡出到后一镜
3. 后一镜开头：产品特写，背景的散景颜色（暖橙色）与前一镜的火光颜色完全匹配
4. 用火焰的光作为转场媒介，既自然又强化"灾难中出现希望（产品）"的叙事

**核心规则**：
- 光媒介转场必须有明确的"动作触发"（穿过入口/火焰充满画面），不是无理由的淡入淡出
- 前后两镜的光线颜色/亮度必须有匹配关系（明→暗、火光橙→散景橙）
- 转场时长0.5-1秒，不能太长（否则观众出戏），也不能太短（否则看不出光线变化）

**适用场景**：从室外进入室内/从开放空间进入封闭空间、从灾难/强光场景转到产品特写、任何需要用光线制造仪式感的转场。
