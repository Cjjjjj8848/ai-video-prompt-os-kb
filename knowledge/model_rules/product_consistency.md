# 产品一致性控制模块（model_rules）

> 保证 AI 生成中产品外观不变形的核心规则。

## 1. 硬性原则

- **产品外观/颜色/logo 以用户图为唯一事实**，提示词不得改设计
- 所有含产品主体镜头，外观描述词必须逐字一致
- 禁止在提示词中"自由发挥"产品细节

## 2. 锁定要素清单

- 外形轮廓、尺寸比例
- 主色/辅色（可用色值固定，如 膏体 #FFB3C7）
- 材质（磨砂/亮面/金属/布料）
- logo/文字（位置、大小、颜色）
- 包装形态

## 3. 提示词写法

```
【产品一致性】外壳白色磨砂、膏体固定色 #FFB3C7、logo 位置固定、
每次出镜角度一致，禁止改动设计
```

## 4. 质检重点（AI 初检 + 人工复核）

- 产品外观变形、颜色漂移、logo 错误（实测批量任务约一成左右需人工复查）
- 标记问题镜头编号与问题类型
- 不合格镜头定向重抽，不整盘重跑

## 5. 预防

- 复杂/易穿模产品走档2逐镜控制
- 高难度镜头用旗舰模型
- 多机位九宫格优先保一致性
