# 质感锚点与画面质感规范（model_rules）

> 来源：小墨分镜 v5.7 §A 质感锚点 + §1 光源动机 + §2 五层色彩。
> 本文件是"画质保险"——每条视频提示词在【画质要求】段落中必须按适用条件选够锚点，靠正面写清楚"要什么质感"来治塑料感/血线/蜡质皮肤/数字锐化，而不是靠堆负面词。

## §1 质感锚点六类（按适用条件选配）

### A.1 清晰度锚点（所有镜头必加）

```
光学锐度，非数码锐化；成像干净通透，主体细节清晰；颗粒与光晕仅作质感点缀，不掩盖细节。
```

**铁律**：禁止"数字锐化感"——那是 AI 视频最廉价的特征。要的是光学镜头的锐利，不是后期 sharpen 滤镜的塑料锐。

### A.2 阴影洁净锚点（low-key / 夜景 / 阴影重必加）

```
暗部深邃而纯净，无噪点污染，深黑处依然通透有细节。
```

**适用条件**：低调光（low-key）/ 夜景 / 阴影重的画面 / 恐怖惊悚题材。明亮高调画面可不加。

### A.3 影调密度锚点（所有镜头必加）

```
完整影调范围，高光胶片式肩部柔和滚降，中间调厚实有密度、色彩浓郁不发灰，暗部浓黑有密度且细节沉入而非发灰上浮；画面有胶片负片般的厚度与体量感。
```

**铁律**：影调发灰是 AI 视频最常见缺陷——中间调发灰、暗部上浮、高光惨白。此锚点确保画面有"胶片体量感"。

### A.4 皮肤质感锚点（人物镜头必加 · 纯场景跳过）

```
皮肤保留真实毛孔与自然纹理，人物表情自然未经摆拍；保留次表面散射（Subsurface Scattering）的通透感；无美颜磨皮、无蜡质感。
```

**铁律**：
- 商业广告片皮肤 = 真实纹理 + 干净无瑕，但**不写病态瑕疵**（不写"瑕疵/泛红/黑眼圈/毛孔粗大"——那是素人纪录片的 DNA，套到商业片会触发血线/伤痕）
- 正确写法：`real skin texture, natural pores, subsurface translucency, clean flawless complexion, no beauty filter, no waxy skin`
- ❌ 禁止：blemishes / under-eye circles / red nose / skin imperfections（这些会让视频模型画出血线）

### A.5 焦外虚化锚点（浅景深镜头必加）

```
焦外为真实镜头光学虚化，背景结构连贯可信、可辨认，绝无涂抹感与绘画笔触。
```

**适用条件**：浅景深镜头（人物特写/情绪聚焦）必加。深景深镜头可不加。

**铁律**：焦外涂抹感是 AI 浅景深最廉价的特征——背景像被 PS 涂抹过。真实光学 bokeh 有圆斑结构。

### A.6 媒介锚点（所有镜头必加）

```
电影实拍剧照，真实摄影质感，{机身名}实拍。
```

**机身名选项**（选一个，不要写多个）：
- `Arri Alexa Mini`（电影感通用）
- `Sony VENICE 2`（高动态范围）
- `RED V-Raptor`（锐利现代感）
- `35mm film`（胶片质感）
- `iPhone 15 Pro`（手机直拍质感，仅手机风格片用）

## §2 光源动机铁律（每处亮度必须有出处）

**画面中每一处亮度都必须有明确来源、方向与真实衰减。**

### 室内光
- 光源必须绑锚点：窗户 / 灯具 / 火源 / 屏幕 / 霓虹，不允许"无来源侧光"
- 窗帘朝向决定时段，整场保持一致
- 光从源头到远处有衰减：近处亮远处暗，有明暗交界
- ❌ 禁止"全局均匀补光"（那是打光板，不是电影光）

### 室外光
- 必须写明是哪一种：太阳（黄金时刻/正午/阴天）/ 月光 / 街灯（钠灯/汞灯）/ 霓虹 / 车灯 / 火光
- ❌ 禁止只写"侧光""环境光"这种无来源描述

### 光参与叙事
- 正面柔光 = 温情；侧逆光 = 神秘；顶光 = 压迫；剪影 = 孤独
- 冷光 = 疏离/专业；暖光 = 亲密/回忆
- 广告片三世界切换时，每个世界的光质必须独立设计，不能三世界共用一种光

### 跨场景光线
- 同一场景内光线物理方向必须一致，只能变强度/色温
- 跨场景（如会议室→街头→夜店）允许光质完全切换，但必须每个场景重新声明光源锚点

## §3 纵深主层机制（替代万能雾/blur）

**每个纵深镜头必须从以下三种机制中只选一种（不堆叠），禁止用 fog/haze/blur 当万能纵深捷径。**

### 三选一

| 机制 | 适用 | 写法 |
|---|---|---|
| **光/曝光分离** | 室内/有光源的主体 vs 背景 | 主体通过有来源的轮廓光或明暗关系与背景分离；近中远景保持不同受光与对比 |
| **大气透视** | 仅外景/大尺度远景 | 远景随距离降低对比、轻微去饱和并偏冷，结构与边缘仍可辨 |
| **遮挡/尺度递退** | 场景有重复建筑/人群/道具 | 描述重叠与尺度递减，不凭空加道具 |

### 物理雾双检
体积光/可见光束只在以下两条同时满足时才写：
1. 场景有可见介质：雾/烟/尘/蒸汽/雨雾/雪/悬浮颗粒
2. 有具名或清晰可见的光源，带方向和衰减

两条缺一不写体积光，改用上述三种主层机制之一。

## §4 五层色彩思维（每镜色调必须五层联动）

| 层 | 含义 | 取值 |
|---|---|---|
| **palette** | 主色调 | 青橙/蓝紫/暖棕/冷灰/霓虹对比/高对比黑白/暖金 |
| **saturation** | 饱和度 | 极低（近黑白）/低（克制）/适度（自然）/中高（鲜艳但不刺眼） |
| **film_stock** | 胶片模拟 | Kodak 250D（日光清新）/Kodak 500T（钨丝灯暖）/Fuji Eterna（低对比柔）/Kodachrome（复古浓郁）/无（数字干净） |
| **grain** | 颗粒 | 无/细腻（barely visible）/中等/粗重 |
| **halation** | 高光溢出 | 无/微弱光晕/暖调光晕 |

### 广告片典型五层组合

- **冷峻专业（职场/科技）**：冷灰 palette × 低饱和 × Kodak 500T × 细腻颗粒 × 无光晕
- **温暖日常（约会/生活）**：暖金 palette × 适度饱和 × Kodak 250D × 细腻颗粒 × 微弱暖光晕
- **夜店/派对**：霓虹对比 palette × 中高饱和 × Kodak 500T × 细腻颗粒 × 微弱光晕
- **产品高级感（黑金/极简）**：高对比黑白 palette × 低饱和 × 无（数字干净）× 无颗粒 × 无光晕

### 软化预算
grain/halation/雾/diffusion/bloom 不能同时全开。**最多 2 项全开**，其余降为 subtle 或省略。强浅景深时降低物理雾或 diffusion。

## §5 锚点组装规则（融入【画质要求】段）

### 必加三件套（所有镜头）
- A.1 清晰度锚点
- A.3 影调密度锚点
- A.6 媒介锚点

### 按条件加
- A.2 阴影洁净 → low-key/夜景/暗调画面
- A.4 皮肤质感 → 有人物的镜头（商业片写"clean flawless"不写"blemishes"）
- A.5 焦外虚化 → 浅景深镜头

### 组装模板

```
【画质要求】
{分辨率}，{palette}色调，{film_stock}胶片质感，{grain}颗粒，{halation}；
{光源动机}，光从{锚点}来，{衰减描述}；
{纵深主层机制：光分离/大气透视/遮挡递退}；
光学锐度非数码锐化，全影调范围胶片肩部滚降，中间调厚实不发灰；
{若有人物}真实皮肤纹理与次表面散射，clean flawless complexion，无美颜磨皮；
{若浅景深}真实光学bokeh，背景结构可辨；
{机身名}实拍，{运动模糊}。
```

### 广告片皮肤锚点的特殊写法（防血线）

商业广告片皮肤段落固定写法：
```
real skin texture with natural pores and subsurface translucency, clean flawless complexion, no beauty filter, no waxy plastic skin, no blemishes, no scratches, no blood
```

**关键**：
- ✅ 正面写"clean flawless"（干净无瑕）
- ❌ 不写"imperfections/blemishes/redness/dark circles"（这些会触发视频模型画出血线/伤痕）
- 负面词加 `no blemishes, no scratches, no blood, no nosebleed`
