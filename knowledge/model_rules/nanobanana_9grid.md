# NanoBanana 九宫格生图规范（model_rules）

> 用 NanoBanana 生成九宫格底图/分镜图时的规则。

## 1. 九宫格用途

- 多机位底图：同一主体多个机位角度，供选首帧
- 分镜总览长图：一张含时间/景别/运镜/画面/对白的总览图
- 风格探索：同一产品多风格对比

## 2. 九宫格提示词结构

```
【任务】九宫格 3×3，同一主体多个机位/视角
【主体】外观锁定描述（颜色/材质/logo）
【机位】9 格分别指定：平视/俯视45°/顶视/侧光/微距/全景/近景/特写/POV
【一致性】每格主体外观完全一致，仅机位光线不同
【光线】统一光源方案
```

## 3. 规则

- 九宫格每格可独立作首帧/分镜图
- 主体一致性优先：宁可机位单调，不可产品变形
- 生成后人工或 AI 质检产品变形/变色/logo 错误，不合格格单独重抽
