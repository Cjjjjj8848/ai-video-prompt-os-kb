# 自动拆镜头 Agent（tools/shot_breaker）

> /蒸馏 时把完整 Prompt 或视频拆成镜头清单的规则。

## 拆解维度

1. **时间轴**：总时长、分镜时间戳（0-3s / 3-7s …）
2. **镜头语言**：每镜景别/机位/运镜/构图
3. **内容**：画面内容、主体、动作链
4. **转场**：段间过渡方式
5. **声音**：口播台词、音效、BGM
6. **节奏**：情绪曲线、镜头密度

## 输出格式

```
镜头清单：
镜1(0-3s) 景别/运镜：画面 + 动作 + 台词 + 音效 → 转场
镜2(3-7s) ...
情绪曲线：起(强钩子) → 中(演绎) → 收(CTA)
```

## 原则

- 逐镜拆解，不留模糊描述
- 拆解结果可直接用于 /学习 提取 DNA，或 /生成 重构
