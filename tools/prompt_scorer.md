# AI 视频 Prompt 评分器（tools/prompt_scorer）

> /学习 与 /优化 时对 Prompt/DNA 打分的规则。

## 评分维度（Prompt 质量）

| 维度 | 权重 | 检查点 |
|---|---|---|
| 结构完整 | 25% | 有任务/主体/分镜/一致性/光影/声音/模型指令 |
| 钩子强度 | 20% | 前 3s 有钩子，反转/反常识/痛点 |
| 动作可执行 | 20% | 动作描述具体，无空话 |
| 产品一致性 | 20% | 外观锁定、@媒体引用正确 |
| 合规 | 15% | 无绝对化用语、无违规表述 |

## 评分输出

```
总分：{X}/100
各维度得分：...
问题点：{列出需修正项}
修改建议：{局部修正话术，不推倒重来}
```

## 用途

- /优化 前评估旧 Prompt 短板
- /学习 前评估候选 DNA 价值
