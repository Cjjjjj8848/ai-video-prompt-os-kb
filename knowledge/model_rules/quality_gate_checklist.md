# 质量门控检查清单（model_rules / quality_gate_checklist）

> V5 P2：6 条质量门控，在 /生成 阶段3（视频提示词最终输出前）强制逐条自检。任何一条不通过必须修正后重新检查，全部通过才能交付。

---

## 门控 1：结构完整性门控

**检查目的**：确保提示词包含所有必需段落，不缺段不缺项。

**检查项**：

| # | 必需段落 | 通过标准 |
|---|---|---|
| 1.1 | 【风格】 | 包含质感关键词+色调关键词+情绪关键词+时长+画幅 |
| 1.2 | 【时间轴】 | 每镜包含：时间段+景别+运镜+机位+画面内容+主体动作+光影 |
| 1.3 | 【BGM总述】 | 包含配乐风格+BPM+情绪曲线+卡点说明 |
| 1.4 | 【参考】 | 每个 @媒体 标注用途，编号连续 |
| 1.5 | 【画质要求】 | 包含分辨率+布光方案+景深+质感+运动模糊+快门速度 |
| 1.6 | 【一致性锁定】 | 包含产品/人物外观锁定+禁止AI改动声明+跨镜一致性说明 |
| 1.7 | 【禁忌】 | 包含画面禁忌+人物/物体禁忌+商业合规禁忌 |

**不通过修正动作**：
- 缺段落 → 立即补全缺失段落
- 段落存在但内容空泛 → 补充具体参数（如"电影级光影"→"顶光+侧逆光双光源，f/1.4极浅景深"）
- 时长/画幅缺失 → 从用户输入或默认值补全

---

## 门控 2：多模态引用门控

**检查目的**：确保 @图片/@视频/@音频 引用规范，编号连续，用途明确，数量不超限。

**检查项**：

| # | 检查项 | 通过标准 |
|---|---|---|
| 2.1 | 编号连续性 | @图片1→@图片2→... 无跳号无重复 |
| 2.2 | 用途标注 | 每个 @媒体 后紧跟"作为XX参考/用于XX"，用途明确 |
| 2.3 | 数量限制 | 图片≤9，视频≤3，音频≤3，总计≤12 |
| 2.4 | 引用位置 | @媒体 出现在【参考】段集中声明，时间轴内引用时编号与声明一致 |
| 2.5 | 必需素材标注 | 产品图/人物图标注"必须上传"，可选素材标注"可选" |
| 2.6 | 视频延长场景 | 视频延长/续拍类必须有 @视频1 原视频，且标注"必须提供" |
| 2.7 | 口播场景 | 口播类必须同时有 @图片1（人物）+ @音频1（语音），且都标注"必须" |
| 2.8 | 多主体权重标注 | 复杂镜头中同时出现产品+人物（或多人物）时，标注视觉焦点占比，如"Focus: 70% Product, 30% Athlete"，避免AI主次不分 |

**不通过修正动作**：
- 编号跳号/重复 → 重新编号，时间轴内引用同步更新
- 用途未标注 → 补充"作为XX参考"
- 数量超限 → 合并同类引用或删除非必要引用
- 必需素材缺失 → 补充声明并标注"必须上传"，或在交付说明中提醒用户
- 多主体无权重 → 在该镜画面描述末尾补充"Focus: X% 主体A, Y% 主体B"

---

## 门控 3：镜头语言门控

**检查目的**：确保运镜/景别/机位/光影使用标准写法，不堆叠，前后连贯。

**检查项**：

| # | 检查项 | 通过标准 |
|---|---|---|
| 3.1 | 标准写法 | 运镜/景别/机位/光影从 camera_language_cheatsheet.md 选取，不临场造词 |
| 3.2 | 运镜不堆叠 | 每镜只一种主运镜（可加一种辅助运镜如"Push in + Orbit"），不超过2种 |
| 3.3 | 光影不堆叠 | 每镜光影只选1-2个关键词，不堆砌5个以上 |
| 3.4 | 景别连贯 | 相邻镜头景别有变化（不连续3镜同景别），变化幅度合理（不大特写直接跳全景） |
| 3.5 | 运镜方向连贯 | 相邻镜头运镜方向不冲突（如一镜向左摇下一镜突然向右摇无理由） |
| 3.6 | 光影连贯 | 同一场景内光线方向/色温一致，场景切换时光影变化有理由 |
| 3.7 | 高速摄影标注 | 爆炸/水花/汗水等冻结瞬间必须标注快门速度（1/500s-1/2000s） |
| 3.8 | 运动模糊标注 | 环绕/跟随/快速运镜段必须标注运动模糊（1/50s-1/100s） |

**不通过修正动作**：
- 临场造词 → 查表替换为标准写法
- 运镜堆叠 → 保留主运镜，删除辅助运镜或拆分为两镜
- 景别跳变 → 插入过渡景别（大特写→特写→近景→中景→全景）
- 光影不连贯 → 统一同场景光线方案，场景切换处加光影变化说明

---

## 门控 4：一致性锁定门控

**检查目的**：确保产品/人物外观跨镜一致，禁止AI改动设计，画质参数具体可执行。

**检查项**：

| # | 检查项 | 通过标准 |
|---|---|---|
| 4.1 | 产品外观锁定 | 【一致性锁定】中包含：形状+颜色+材质+logo位置+尺寸，明确"禁止AI改动设计" |
| 4.2 | 人物外观锁定 | 有人物时包含：性别+体型+发型+服装+五官特征，明确"不磨皮" |
| 4.3 | 每镜重复锁定 | 时间轴内每次产品/人物出镜都重复外观描述（至少关键属性），不依赖【一致性锁定】段单独说明 |
| 4.4 | 液体/颜色固定 | 涉及液体/发色/服装颜色时，明确"固定为XX色，不偏移" |
| 4.5 | 画质参数具体 | 分辨率（8K/4K）+ 布光（具体光源方案）+ 景深（f值等效）+ 质感（胶片/数码）+ 快门速度 + 运动模糊 |
| 4.6 | 高光控制 | 产品/金属/液体反光处标注"高光不过曝，保留细节" |
| 4.7 | 表情变化合理 | 人物表情跨镜变化有叙事逻辑（疲惫→坚定→爆发），不突兀跳变 |

**不通过修正动作**：
- 锁定描述缺失 → 补充完整外观属性+禁止改动声明
- 时间轴内未重复 → 在每次出镜的画面描述中加入关键外观属性
- 画质参数空泛 → 补充具体数值（f/1.4、1/1000s、8K等）
- 表情跳变 → 补充过渡表情或调整叙事节奏

---

## 门控 5：商业合规门控

**检查目的**：确保提示词不侵犯版权、不涉及敏感内容、符合商业广告规范。

**检查项**：

| # | 检查项 | 通过标准 |
|---|---|---|
| 5.1 | 真实品牌名 | 无真实品牌名（可口可乐/耐克/苹果等），用通用名替代（"运动饮料"/"运动鞋"/"智能手机"） |
| 5.2 | 知名角色名 | 无知名角色名（蜘蛛侠/哈利波特/孙悟空等），用"Figure 1"/"Figure 2"替代 |
| 5.3 | 真实人物 | 无真实公众人物姓名/外貌描述，用通用人物设定替代 |
| 5.4 | 血腥暴力 | 无血腥/暴力/自残/虐待描写，动作场面保持美感不特写血腥 |
| 5.5 | 政治敏感 | 无政治敏感元素/敏感事件/敏感人物/敏感旗帜 |
| 5.6 | 色情低俗 | 无色情/低俗/性暗示内容，人物着装得体 |
| 5.7 | 虚假宣传 | 无虚假功能演示/夸大效果（如"喝了立刻长高"），产品功能描述合理 |
| 5.8 | 危险道具 | 涉及武器/危险道具时明确标注"玩具/塑料质感/非真实"，不教制作方法 |

**不通过修正动作**：
- 真实品牌名 → 替换为通用名
- 知名角色名 → 替换为 Figure 1/2 + 外观描述
- 血腥暴力 → 删除血腥特写，保持动作场面美感
- 虚假宣传 → 修改为合理功能描述
- 危险道具 → 补充"玩具/塑料质感/非真实"标注

---

## 门控 6：内聚化格式门控

**检查目的**：确保 P0 内聚化格式严格执行，声音内嵌分镜，转场显性化。

**检查项**：

| # | 检查项 | 通过标准 |
|---|---|---|
| 6.1 | 声音内嵌 | 每个分镜下方有 `└─ 声音：` 行，不集中放在时间轴之后的独立大块 |
| 6.2 | 声音分层 | 每镜声音标注时间段+分层（环境音/动作音/情绪音/对白），不笼统写"有音效" |
| 6.3 | 转场标注 | 每个分镜下方有 `└─ 转场：` 行（单场景同景别相邻镜可写"硬切"或省略，但多场景切换处必须明确） |
| 6.4 | 多场景转场显性 | 场景切换处（写实→纯黑→特效→品牌等）转场方式具体（匹配剪辑/能量转场/甩镜/叠化），不写"自然过渡" |
| 6.5 | BGM独立 | 整体配乐风格放在【BGM总述】段，不拆散到每镜（每镜只写该镜的动作音/情绪音/对白） |
| 6.6 | 格式符号统一 | 使用 `└─ 转场：` 和 `└─ 声音：` 统一前缀，不混用其他符号 |
| 6.7 | 时间精确 | 声音时间段精确到0.5秒（如[5.0-5.5s]），不写"开头"/"中间" |
| 6.8 | 语言一致性+中英双文 | 所有提示词必须输出中英双文版，先中文后英文，分开输出不混排，每版独立完整块；英文版正文无中文字符残留（如"极速冲入""叠入""收束""空气感"等），中文版无未翻译的英文术语；段落标题（【风格】【时间轴】等）可保留中文标记 |

**不通过修正动作**：
- 声音集中放置 → 拆分到每镜下方，保留【BGM总述】独立
- 声音笼统 → 补充时间段+分层+具体音效描述
- 多场景转场缺失 → 补充具体转场方式（匹配剪辑/能量转场等）
- 格式不统一 → 统一为 `└─ 转场：` / `└─ 声音：` 前缀
- 英文版有中文残留 → 逐词替换为英文（极速冲入→Fast Zoom-in，叠入→overlay，收束→converge，空气感→airy atmosphere）
- 中英混排 → 拆分为中文完整块+英文完整块，先中后英，不交叉混排

## 门控执行流程

```
阶段3 视频提示词生成
  │
  ▼
生成提示词初稿
  │
  ▼
逐条过 6 条门控（门控1→门控2→...→门控6）
  │
  ├─ 全部通过 → 输出提示词 + 门控自检表
  │
  └─ 任意一条不通过 → 修正对应问题 → 重新过该条门控 → 全部通过后输出
```

## 输出格式要求

最终交付时，提示词之后必须附门控自检表：

```
## 📋 P0+P1+P2 质量门控自检

| 门控 | 状态 | 关键检查点 |
|---|---|---|
| 1. 结构完整性 | ✅/❌ | 7段齐全，参数具体 |
| 2. 多模态引用 | ✅/❌ | 编号连续，用途明确，数量合规，多主体权重标注 |
| 3. 镜头语言 | ✅/❌ | 标准写法，不堆叠，前后连贯 |
| 4. 一致性锁定 | ✅/❌ | 外观锁定+每镜重复+画质参数具体 |
| 5. 商业合规 | ✅/❌ | 无真实品牌/角色/血腥/敏感 |
| 6. 内聚化格式 | ✅/❌ | 声音内嵌+转场显性+格式统一+语言一致性 |

**Overall: X/6 passed. Ready for Seedance generation / 修正后重新检查**
```

## 与外部仓库质检的差异

| 维度 | 外部仓库质检 | V5 P2 质量门控 |
|---|---|---|
| 检查重点 | 提示词质量（描述是否生动/完整） | 商业交付确定性（防崩/防变形/防合规风险） |
| 门控数量 | 6条通用检查 | 6条专项门控（结构/多模态/镜头/一致性/合规/格式） |
| 修正动作 | 建议优化 | 强制修正后重新检查 |
| 输出要求 | 可选 | 必须附门控自检表 |
| 适用范围 | 所有提示词 | 商业广告/产品展示/人物类提示词强制，创意类可选 |
