# 人物四视图模板（templates/nanobanana/character_turnaround）

> 角色一致性参考表（character turnaround / model sheet）：一次输出同一人物的四视角（脸部特写/全身正面/全身侧面/全身背面），用于角色设定、服装 lookbook、IP 建模参考、电商模特一致性，以及后续生图/生视频前锁定外观。
> 核心 DNA：DNA-050（四竖栏分屏构图）/ DNA-051（--cref/--cw 锁脸）/ DNA-052（亮白影棚 lookbook 视觉）。
> 详细规范见 `knowledge/model_rules/character_turnaround_spec.md`。

---

## 场景 A：有人物素材参考（--cref 锁脸，严格不改参考图）

**适用**：手上已有一张（或脸/身两张）满意的人物图，要求四视图且面部、发型、肤色、配饰、服装全部与参考图一致，只换视角。

```
【任务】model sheet，4-view character turnaround，均匀分为四个竖栏：第1栏脸部胸像特写，第2栏全身正面，第3栏全身侧面，第4栏全身背面
【参考锁定】脸部特写参考[你的脸部参考图URL]，全身参考[你的全身参考图URL]
【主体锁定】严格使用参考图中的同一{人物：性别/年龄}——{发型}、{五官特征}、{肤色}、{配饰}、{服装：款式/颜色/材质}。禁止改动参考图中任何面部特征、五官形状、肤色、痣、发型、配饰与服装颜色。
【视觉规则】{背景/灯光：如亮白影棚，柔和窗光，地面柔和窗影投影}，{风格：high fashion lookbook，照片级写实，8k}
【参数】--cref [你的参考图URL] --cw 100 --ar 16:9 --v 6.1
```

**参数要点**：
- `--cw 100` = 最强锁脸，100% 保留参考图人物面部
- 若四视图服装被改但脸要保留 → 降到 `--cw 75` 给服装一点自由度
- 若脸跑偏 → 保持 100，并在提示词里把五官特征写死两遍

---

## 场景 B：没有人物素材参考（纯文字锁特征，直接出四视图）

**适用**：没有参考图，从零描述一个人物并直接出四视图。无图锁脸，必须在提示词里把识别特征写得足够具体、每栏隐含重复，否则四栏会变成四个不同的人。

```
【任务】model sheet，4-view character turnaround，均匀分为四个竖栏：第1栏脸部胸像特写，第2栏全身正面，第3栏全身侧面，第4栏全身背面
【主体锁定】四栏必须是同一个{人物：性别}：{年龄}左右，{肤色}，{发型：发色/造型/碎发}，{五官：眉/眼/鼻/唇/痣，逐项写死}；佩戴{配饰：耳环/项链等}。身穿{服装：款式/颜色/材质}，脚踩{鞋}。所有四栏保持完全相同的发型、五官、配饰、服装颜色与身材比例。
【一致性强调】All four panels must show the SAME {person} / 所有四栏保持完全相同的{特征}——禁止四栏出现不同人。
【视觉规则】{背景/灯光：如亮白影棚，柔和窗光从左侧打入，地面柔和窗影投影}，{风格：high fashion lookbook，照片级写实，8k}，{材质肌理：如亚麻材质肌理，oversize垂坠廓形}
【参数】--ar 16:9 --v 6.1
```

**要点**：识别特征必须自包含（年龄/肤色/发型/五官/痣/配饰/服装/鞋/身材比例），并在每栏描述中重复锁定；无 --cref 时参数不加 --cref/--cw。

## 双场景差异速查

| 维度 | A・有参考图 | B・无参考图 |
|---|---|---|
| 锁脸手段 | `--cref [图] --cw 100` | 文字死写五官+痣+配饰，强调 "same across all panels" |
| 提示词长度 | 短（外观交给参考图） | 长（必须自包含全部识别特征） |
| 风险 | --cw 太低会换脸 | 四栏易跑偏成四个人 |
| 替换位 | 只换 [你的参考图URL] | 换年龄/肤色/五官/服装整段描述 |

---

## 使用流程

1. 判断是否有参考图 → 选场景 A 或 B
2. 填写主体锁定（A 引用参考图 + 外观确认；B 文字写死全部识别特征）
3. 选择视觉规则（默认亮白影棚 lookbook，可按需换背景/灯光/风格）
4. 输出中英双文版（先中文后英文，分开输出不混排，英文版无中文残留）
5. 过 4 条四视图质量门控（见 `character_turnaround_spec.md` 第6节），附自检表
6. 生成后检查四栏一致性，跑偏栏单独重抽
