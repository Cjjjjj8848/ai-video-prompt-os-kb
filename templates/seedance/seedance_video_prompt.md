# Seedance 视频 Prompt 模板（templates/seedance）

> 通用视频提示词模板，直接复制后按任务填充。

## 模板（15s 通用带货版）

```
【任务】15秒 {画幅：9:16/16:9} {品类} 短视频 · {模型：Seedance 2.0}
【产品/主体】{名称} · 卖点：{2-3 条} · 人群：{人群画像}

── 前3秒 钩子 ──
Shot1(0-1s)  {景别} {画面}，{动作}，{音效}
Shot2(1-3s)  {反转/钩子内容}，字幕"{钩子文案}"

── 中段 卖点演绎 ──
Shot3(3-7s)  {动作链 1}：{具体动作描述}
Shot4(7-10s) {动作链 2}：{具体动作描述}
Shot5(10-13s){场景/切换}：{内容}

── 收尾 CTA ──
Shot6(13-15s){产品定格}，字幕"{CTA 文案}"，口播"{CTA 话术}"

【产品一致性】{外观锁定描述}，每次出镜角度一致
【光影】{具体灯光方案}
【声音】{音效层级}；BGM {风格}
【模型指令】@媒体{编号} 作{用途}；负向：{负面项}

── 画质与一致性锁定（必填，详见 model_rules/quality_and_consistency.md）──
【画质要求】8K分辨率，{光影方案}，{景深}，{质感风格}，{细节}，{运动模糊}
【一致性锁定】严格还原参考图{五官/产品外观/服装}，不做{磨皮/改设计}，保持{真实质感/颜色/logo}
【禁忌】无字幕/水印/UI/数字乱码；无畸形/穿模/多余肢体/过度油光
```

## 填充示例（唇膏）

```
【任务】15秒 9:16 唇膏种草短视频 · Seedance 2.0
【产品】XX 变色润唇膏 · 卖点：千人千色、滋润不黏腻 · 人群：18-25 学生/职场

── 前3秒 钩子 ──
Shot1(0-1s)  特写微距：开盖瞬间，膏体旋转上升，指尖轻旋出"咔哒"ASMR
Shot2(1-3s)  反转 hook：干裂素唇特写 → 镜头快速推近唇膏，字幕"一支搞定"

── 中段 卖点演绎 ──
Shot3(3-7s)  涂抹动作链：45°倾斜抹过下唇→上唇，膏体顺滑推开，水光反射
Shot4(7-10s) 变色过程：唇色由浅粉渐变为水蜜桃色，延时特写颜色变化
Shot5(10-13s) 场景切：对镜抿唇、微笑，自然光无滤镜感

── 收尾 CTA ──
Shot6(13-15s) 手持产品旋转定格，字幕"链接在左下角"，口播"评论区扣 1 我发色号"

【产品一致性】膏体固定色 #FFB3C7、白色磨砂外壳、每次出镜角度一致
【光影】窗边自然光 + 环形补光，柔光无硬阴影
【声音】ASMR：开盖/旋出摩擦/抿唇声；BGM 轻快流行
【模型指令】@媒体1(产品实拍) 作主体；负向：模糊、畸形手指、过度油光、乱码文字

【画质要求】8K分辨率，电影级柔和光影，主光源前方偏上偏左均匀铺陈，无生硬阴影；极浅景深背景虚化，焦点咬住唇部细节；自然光胶片质感与细腻灰阶，通透空气感，1/50s–1/100s自然物理运动模糊。
【一致性锁定】严格还原 @媒体1 产品外观：白色磨砂外壳、淡黄色膏体、蜜蜂logo，不改变设计，保持材质纹理，每次出镜角度一致。
【禁忌】无字幕水印UI乱码；无畸形手指/多余肢体/穿模/过度油光/产品变形。
```
