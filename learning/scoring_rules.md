# DNA 评分与去重规则（learning/scoring_rules）

> /学习 入库前必须执行的评分与去重流程。

## 1. 评分维度

| 维度 | 分值 | 判定 |
|---|---|---|
| 新颖性 | 0-2 | 与现有 DNA 结构差异度 |
| 复用性 | 0-2 | 能否跨产品/跨任务套用 |
| 清晰度 | 0-1 | 指令可执行、无歧义 |

总分 5 分制：
- ≥4 分：直接入库
- 3 分：进 pending_updates.md 待审
- <3 分：丢弃

## 2. 去重规则

- 按 (category + name 归一化 + description 语义) 比对
- 完全重复 → 丢弃
- 高相似 → 保留高分，合并描述
- 新结构 → 新建条目

## 3. 入库流程

1. 评分
2. 去重
3. 编号（DNA #N+1 递增）
4. 写入 DNA.json + 对应分类库
5. 更新 learning_log.md
6. 模式 B：commit 到 GitHub
