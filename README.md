# AI Video Prompt OS V6

一套「Prompt DNA 蒸馏 + 可进化知识库 + 分镜决策引擎 + 生成」的视频/生图提示词系统。

**当前版本**：V6.0.0 · 71 条 DNA · 八维框架 · 四档分镜决策引擎

## 核心能力

通过五个命令完成提示词全生命周期管理：

| 命令 | 作用 |
|---|---|
| `/蒸馏` | 分析优秀视频/生图 Prompt，提取**八维 DNA**（镜头/运镜/转场/动作/时间/视觉+🔴声音+🔴台词），每条标注 app（video/image/both） |
| `/学习` | 蒸馏→评分→去重→合并→写回知识库 |
| `/生成` | **阶段0判档(L1/L2/L3/L4)** → 按 app 过滤 → 检索 DNA → 锚点地图 → 逐镜头关键帧 → 按档质检 → 视频 Prompt |
| `/优化` | 局部修正已有 Prompt，不推倒重来 |
| `/同步` | 拉取最新知识库（GitHub），建立会话索引 |

## 快速开始

1. 复制 `SKILL.md` 到智能体 Instructions
2. 上传 `knowledge/`、`templates/` 作为知识文件
3. 输入 `/蒸馏` 测试部署
4. （可选）连接 GitHub，用 `/同步` 拉取最新知识

## 运行模式

- **本地库模式**：直接读取项目内知识库，无需联网
- **GitHub 增强模式**：`/学习` 自动 commit 到 GitHub，`/同步` 拉取远程最新知识

## 硬性原则

- 产品外观/颜色/logo 以用户图为唯一事实
- 具体工具名不写死，只保留模型分层策略
- 每阶段产物可直接复制使用，不给半成品
- 先验证再放量：先出 2-3 条测方向
