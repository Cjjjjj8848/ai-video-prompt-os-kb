**当前版本**：V9.0-精简版 · 结果思维 · 4块提示词（画面/动作/声音/防翻车）· 5种光学风格单选 · 物理因果锁定

## V9.0 核心转变：从「相机参数思维」到「画面结果思维」

AI 视频模型不是相机，不按 ISO、f值、快门、白平衡渲染，它吃的是「画面结果」。所以最终提示词只讲 4 件事：**画面、动作、声音、防翻车**。真正起作用的是：参考图 + 风格锚点 + 物理因果 + 结果描述；参数堆砌和画质堆词全部删掉。

## V9.0 瘦身要点（删了为什么效果不变）

1. **画质堆词（8k/photorealistic/ultra detailed）** → 只留一个风格锚点：真实感是模型基础能力，堆词不增效
2. **相机参数（ISO/f值/快门/白平衡）** → 改成结果描述（背景虚化/手持微抖）：模型不按参数渲染
3. **动作写两遍** → 只写一遍：纯重复
4. **色彩逻辑+光影逻辑分开** → 合并进画面：本质都是画面长啥样
5. **负面约束 20-30 条** → 只留该镜头真正会翻车的 3-5 条：视频模型对负面词遵循弱，正向描述更有效

## 质量门控（13条）

1. 前3秒有抓手
2. 4块齐全，无模块标题、无重复
3. 结果思维，无参数堆砌、无画质词堆砌
4. 物理因果4要素
5. 光学风格单选，无混搭
6. @图内嵌，有参考图处无外观描述
7. 物理质感真实
8. 见证瞬间清晰
9. 运镜稳定，无组合套招
10. 长镜头有状态阶梯
11. 首尾闭环
12. 声音同步，BGM不压人声
13. 防翻车只写重点（3-5条）
