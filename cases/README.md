# 优秀 Prompt 案例库（cases）

> 蒸馏素材来源。收录跑通过的优秀 Prompt / 脚本 / 爆款拆解。

## 收录规范

每个案例一份文件（`case_XXX_名称.md`），包含：

1. 原始 Prompt / 视频链接（来源）
2. 蒸馏出的 DNA（引用 DNA 编号或新增草稿）
3. 评分（novelty / reusability / clarity / total）
4. 适用场景与复用建议

## 分类管理

- `case_*_爆款拆解.md`：逆向重构的爆款结构分析
- `case_*_带货脚本.md`：跑通的带货脚本
- `case_*_电影分镜.md`：电影级分镜参考
